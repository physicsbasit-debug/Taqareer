ارفع الملف، ودع «تقارير» يفهمه ويحلله تربويًا مع بقاء الأدلة والحسابات قابلة للمراجعة.

    طبقة الذكاء الاصطناعي

    اختيارية مع رجوع محلي

    أدخل رابط وظيفة Supabase والمفتاح العام مرة واحدة، ثم يتولى التطبيق بقية العمل.

    • قراءة الصور وملفات PDF الممسوحة.
    • فهم نوع النموذج وهدفه حتى عند ظهور نوع جديد.
    • ربط الاستنتاجات بمراجع صفوف أو أسطر أو مؤشرات.
    • اقتراح أدوات الجودة وخطة تحسين قابلة للقياس.
    لا يوضع مفتاح Gemini داخل GitHub Pages. يُحفظ في أسرار وظيفة Supabase، بينما يحتفظ المتصفح فقط برابط الوظيفة والمفتاح العام الآمن.

    المحرك الحتمي

    • العد والمتوسط والوسيط والمدى.
    • فحص الاكتمال والتكرار والقيم غير الصالحة.
    • نسبة الإتقان عند تأكيد الدرجة الكلية.
    • عدم اختراع قيم ناقصة أو استنتاج سببية من مجرد نمط.
