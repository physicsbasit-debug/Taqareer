    وضع محلي آمن

    تعمل هذه النسخة بمحرك استدلال محلي قابل للمراجعة. الربط الحي سيأتي عبر وظيفة خادمية آمنة، لا بوضع مفتاح API داخل المتصفح كمن يترك مفتاح البيت تحت السجادة ثم يعلن عن ابتكار أمني.

    • فهم النوع والبنية.
    • صياغة استنتاجات من المؤشرات المحسوبة.
    • ربط كل استنتاج بأدلة رقمية واضحة.
    • إظهار حدود الثقة بدل إخفائها.

    المحرك الحتمي

    • العد والمتوسط والوسيط والمدى.
    • نسبة اكتمال البيانات والقيم المفقودة.
    • نسبة الإتقان عند تأكيد الدرجة الكلية.
    • اكتشاف التكرارات والقيم غير الرقمية.
