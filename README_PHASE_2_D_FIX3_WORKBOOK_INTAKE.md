# Phase 2-D Fix 3 — Reliable Workbook Intake & Subject Selector

## الإصدار

- التطبيق: `v1.2.3`
- Supabase Edge: `V0.15.2` دون تغيير
- عقد التحليل: `6.6.0` دون تغيير
- Semantic Profile: `2.0.0` دون تغيير

## المشكلة

في بعض مصنفات نتائج الطلبة ظهر نوع `multi_subject_results` بصورة صحيحة، لكن قائمة المادة بقيت فارغة، ثم انتهى التنفيذ برسالة تفيد بعدم اكتشاف عدد كافٍ من أزواج الدرجة والمستوى.

السبب لم يكن في محرك الترتيب أو Gemini، بل في طبقة إدخال Excel والربط مع الواجهة:

1. قارئ XML كان يفترض وسوم OOXML بلا بادئة namespace.
2. اكتشاف أزواج المستوى والدرجة كان يفترض موضعًا واتجاهًا ثابتين.
3. اكتشاف الاسم والقيد والجنسية كان يبحث في جهة واحدة فقط من كتلة المواد.
4. بيانات `specializedType` و`metadata` لم تكن تمرر كاملة من الورقة إلى حالة التطبيق.
5. قائمة المواد اعتمدت على مصدر واحد فقط هو `semanticProfile.columnRoles.subjects`.
6. ملفات JavaScript وCSS لم تكن تحمل بصمة إصدار، ما يسمح للمتصفح بخلط `index.html` جديد مع قارئ Excel قديم محفوظ مؤقتًا.

## العلاج الجذري

### قارئ OOXML

أصبح القارئ يدعم الوسوم القياسية والوسوم ذات البادئة مثل:

```xml
<x:worksheet>
<x:row>
<x:c>
```

ويشمل ذلك workbook، العلاقات، shared strings، styles، worksheets، الخلايا، الصفوف، الأعمدة، الدمج، والأبعاد.

### اكتشاف أزواج الدرجة والمستوى

أصبح المحرك:

- يفحص كل بداية ممكنة داخل الورقة.
- يدعم `المستوى ثم الدرجة`.
- يدعم `الدرجة ثم المستوى`.
- يختار أطول كتلة متصلة ذات جودة بيانات كافية.
- لا يفترض أن المواد تبدأ من العمود الأول.

### اكتشاف هوية الطالب

يبحث المحرك عن:

- الرقم.
- اسم الطالب.
- حالة القيد.
- الجنسية.

في جميع الأعمدة الواقعة خارج كتلة المواد، سواء سبقتها أو جاءت بعدها. الاسم والرقم هما الأساس، بينما تبقى حالة القيد والجنسية اختيارية عند غيابهما.

### اختيار الورقة

إذا احتوى المصنف ورقة نتائج شاملة وأوراق شعب أصغر، وكانت الورقة الشاملة أكبر بوضوح، يختارها التطبيق تلقائيًا. وإذا لم توجد ورقة مهيمنة، تبقى نافذة اختيار الورقة وتعرض بجانب الورقة المكتشفة عدد المواد.

### استعادة قائمة المواد

تُبنى قائمة المادة الآن من ثلاثة مصادر محلية مرتبة:

1. أدوار الأعمدة في الملف الدلالي.
2. بيانات الورقة ونتيجة التطبيع.
3. أسماء الأعمدة المنتهية بـ `- الدرجة` والمقترنة بعمود `- المستوى`.

إذا لم تُكتشف مادتان على الأقل، يمنع التطبيق التنفيذ ويطلب اختيار ورقة النتائج الشاملة بدل إرسال بنية ناقصة إلى محرك التحليل.

### منع ذاكرة المتصفح القديمة

تحمل ملفات CSS وJavaScript الآن الاستعلام:

```text
?v=1.2.3
```

وبذلك لا تختلط واجهة `v1.2.3` بقارئ أو منطق من إصدار سابق.

## المكتسبات المحفوظة

لم يتغير:

- محرك ترتيب الأوائل.
- معادلات 70/30 و60/40.
- المواد الأساسية المعتمدة.
- قاعدة التعادل دون كسر.
- استبعاد ناقص المادة الأساسية.
- الخصوصية وعدم إرسال الأسماء والجنسية إلى Gemini.
- التوجيه الدلالي التكيفي.
- محرك الزيارات المتعددة.
- حراس الأرقام والنطاق.
- التقارير الرسمية والرسوم.
- Edge Function `V0.15.2`.

## اختبار القبول

بعد النشر ورفع كشف النتائج:

1. لا تبقى قائمة المادة فارغة.
2. تظهر أسماء المواد المكتشفة.
3. يظهر عدد المواد في ملاحظة مساحة التحليل.
4. يمكن اختيار `تحليل مادة محددة` ثم اختيار المادة.
5. لا تظهر رسالة «لم يكتشف التطبيق أزواج الدرجة والمستوى» للورقة الصحيحة.
6. إذا كان المصنف يحتوي ورقة شاملة وأوراق شعب، تُفتح الورقة الشاملة تلقائيًا عندما تكون مهيمنة بوضوح.
