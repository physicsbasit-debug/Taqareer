# تقارير v1.2.7

منصة تحليل تربوي تكيفية تعمل على GitHub Pages، مع Supabase Edge Function لربط Gemini بوصفه المحلل التربوي الأساسي، بينما تبقى القراءة والحسابات والترتيب والرسوم والتحقق العددي محلية المصدر.

## Phase 2-D Fix 7 — Compact Neutral Professional Reporting

يعالج هذا الإصدار عرض التقرير نفسه دون تغيير الحسابات أو منطق التحليل أو Supabase Edge.

### ما تغير في التقرير

- لا يعرض التقرير أي عبارة تفصح أن التحليل أُنتج بالذكاء الاصطناعي؛ استبدلت حالة «تحليل ذكاء اصطناعي موثق» بعبارة مهنية محايدة: «تحليل تربوي موثق».
- أزيلت معرفات التقرير العشوائية من نوع `TQR-...` من الترويسة ومن عنوان الصفحة الأولى.
- استبدل توصيف العلامة داخل التقرير بـ«منصة التحليل التربوي والبيانات التعليمية».
- أعيد بناء صفحات ترتيب المواد لتجميع الجداول القصيرة في الصفحة نفسها وتقسيم الجداول الطويلة تلقائيًا دون إسقاط حالات التعادل.
- أضيف فحص بصري داخل التقرير لرصد خروج أي جدول ترتيب عن حدود الصفحة.
- الرسم التكميلي القصير لا يحصل على صفحة مستقلة إذا أمكن دمجه بأمان مع صفحة القراءة التفسيرية.

## Phase 2-D Fix 6 — Fast Bounded Primary AI

يعالج هذا الإصدار مشكلة انتظار التحليل الذكي حتى مهلة العميل ثم ظهور رسالة الفشل، رغم وجود مهلة خادم مفترضة.

### السبب الجذري الذي عولج

في مسار Gemini السابق كانت مهلة المحاولة تحيط بانتظار `fetch()` فقط، ثم تُلغى المؤقتات قبل قراءة `response.text()`. إذا وصلت ترويسات HTTP وبقي جسم الاستجابة متعثرًا أو بطيئًا، أمكن لوظيفة Edge أن تتجاوز ميزانية الخادم بينما يظل المتصفح ينتظر حتى يقطع الطلب بعد 85 ثانية.

### العلاج

- تبقى مهلة محاولة Gemini فعالة حتى **اكتمال قراءة جسم الاستجابة**، وليس حتى وصول الترويسات فقط.
- النموذج الأساسي أصبح `gemini-3.6-flash`.
- الانتقال السريع عند ازدحام/تعثر النموذج إلى `gemini-3.5-flash-lite`.
- خُفضت مهلة محاولة النموذج الأساسي إلى 16 ثانية.
- خُفضت مهلة مسار الإنقاذ إلى 12 ثانية.
- أصبحت ميزانية Edge الكلية 42 ثانية، ومهلة العميل 52 ثانية لإبقاء هامش آمن لعودة استجابة Edge.
- خُفض حد الإخراج الطبيعي من 8192 إلى 4096 token، ومسار الإنقاذ من 6144 إلى 3072 token، مع بقاء عقد التحليل 6.6.0 والتحقق البنيوي كما هو.
- واجهة التقدم توضّح أن الخادم ينتقل تلقائيًا إلى نموذج أسرع عند تعثر الاستجابة.

## ما لم يتغير

- Gemini يبقى المحلل التربوي الأساسي، ولا تُعرض قوالب محلية على أنها تحليل عميق.
- الحسابات والرسوم والأرقام المحلية تبقى مصدر الحقيقة.
- عقد التحليل `6.6.0` لم يتغير.
- Semantic Profile `2.0.0` لم يتغير.
- معادلات ترتيب المدرسة/الدفعة، التعادلات، حارس مصدر المستويات، التقرير التنفيذي والتقرير الكامل لم تتغير.
- لا SQL جديد ولا Secret جديد.

## تحليل النتائج متعددة المواد

يدعم التطبيق التحليل الشامل لجميع المواد أو تحليل مادة محددة، والعشرة الأوائل في كل مادة، وترتيب المدرسة أو الدفعة وفق المعادلات المعتمدة، مع إبقاء الأسماء والجنسية محليًا وعدم إرسالهما إلى Gemini.

### معادلات ترتيب المدرسة/الدفعة

- الصفوف 5–9: `70% متوسط المواد الأساسية + 30% متوسط جميع المواد`.
- الصفوف 10–12: `60% متوسط المواد الأساسية + 40% متوسط جميع المواد`.

المواد الأساسية للصفوف 5–8: العربية، التربية الإسلامية، الدراسات الاجتماعية، الرياضيات، الإنجليزية، والعلوم.  
المواد الأساسية للصفوف 9–12: العربية، التربية الإسلامية، الدراسات الاجتماعية، الرياضيات، الإنجليزية، الفيزياء، الكيمياء، والأحياء.
