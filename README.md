# تقارير v1.0.5

تطبيق لتحليل الاستمارات والبيانات التربوية، يفصل بين **الحساب الموثوق** و**التحليل الذكي**:

- المتصفح يقرأ الملفات ويحسب المؤشرات والرسوم ومراجع الأدلة.
- Gemini هو المحلل التربوي الأساسي.
- بوابات التحقق تمنع الأرقام والمراجع المختلقة والنتائج الناقصة.
- لا تُعرض قوالب محلية محفوظة بوصفها تحليلًا عميقًا.

## جديد Phase 2-B Fix 1

- عقد `6.4.0` يجعل حساب أهداف تدخلات الدرجات مملوكًا للخادم.
- Gemini يختار الفئات ونوع التدخل، لكنه لا يملك اختراع العدد النهائي أو نسبة النجاح.
- معرفات ثابتة للفئات: `mastery`, `near_mastery`, `moderate_gap`, `deep_gap`.
- حارس رياضي يمنع أن يتجاوز عدد المنتقلين حجم الفئات المستهدفة.
- إذا كان الهدف مستحيلًا، يُخفض إلى الحد الممكن بدل عرضه بثقة مزيفة.
- المتصفح يعيد التحقق من الحسابات قبل عرض التقرير.
- بقيت مكتسبات `v1.0.4`: ثلاثة محاور، تدخلات متمايزة، ثلاث مراحل متابعة، التفكير المضبوط، ومسار الإنقاذ.
