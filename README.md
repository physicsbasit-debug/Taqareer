# تقارير v0.9.5

## جديد v0.9.5

- تفكيك محور أدوات الجودة إلى مهمة Gemini صغيرة مستقلة لكل أداة.
- حد أقصى مهمتان جودة بالتوازي.
- فشل تحسين أداة واحدة لا يعطل اكتمال التقرير؛ يبقى تفسير المحرك المحلي الآمن.
- عرض عدد أدوات الجودة المحسنة بالذكاء وعدد الأدوات التي اعتمدت التفسير المحلي.


تطبيق التحليل التربوي التكيفي العميق للاستبانات ونتائج الطلبة والزيارات الإشرافية وأعمال الطلبة والبرامج وغيرها، مع محللات متخصصة لكل نوع.

## هذا الإصدار

يعالج حلقة فشل جزء Gemini التي كانت تعيد الطلب نفسه وتصل إلى زمن طويل دون كشف الجزء الحقيقي المتعثر.

- الجودة والمتابعة منفصلتان داخليًا.
- فشل المحتوى يؤدي إلى تفكيك المهمة، لا تكرارها.
- أخطاء الاتصال المؤقتة تحصل على إعادة واحدة فقط.
- يظهر اسم المهمة وسبب الفشل.
- تعاد المهمة الفاشلة فقط، مع بقاء النتائج والمهام الناجحة.
