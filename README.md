# تقارير v0.9.6

تطبيق ويب عربي لتحليل الاستمارات والبيانات التربوية بصورة متخصصة حسب نوع كل استمارة، مع تطبيع ملفات Excel الوزارية، تحليل حتمي عميق، رسوم وأدوات جودة، وتقرير رسمي قابل للطباعة.

## جديد v0.9.6

أعيد بناء مسار الذكاء الاصطناعي وفق عقد المشروع: **البساطة، السهولة، والسرعة**.

- التقرير المحلي الكامل يظهر فورًا.
- Gemini يعمل في الخلفية عبر طلب اختياري واحد فقط.
- لا تقسيم إلى مهام أو عدادات تقدم تقنية.
- لا إعادة تلقائية متكررة ولا انتظار 60–80 ثانية.
- مهلة التحسين الذكي 16 ثانية، وبعدها يبقى التقرير المحلي جاهزًا.
- التخزين المؤقت يمنع تكرار الطلب للملف والإعدادات نفسها.
- الحسابات ومعادلات بوصلة الإتقان وأدوات الجودة لا تعتمد على Gemini.
