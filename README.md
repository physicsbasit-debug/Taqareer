# تقارير v1.0.1

تطبيق لتحليل الاستمارات والبيانات التربوية، مبني على فصل واضح بين **الحساب الموثوق** و**التحليل الذكي**:

- المتصفح يقرأ الملف وينظف البيانات ويحسب المؤشرات والرسوم ومراجع الأدلة.
- Gemini هو المحلل التربوي الأساسي، ويُنشئ التشخيص والاستنتاجات والفرضيات والتدخلات من الأدلة.
- بوابتان، خادمية ومحلية، تمنعان المراجع المختلقة والنتيجة الناقصة.
- لا يعرض التطبيق قوالب محلية محفوظة على أنها تحليل عميق عند فشل الذكاء الاصطناعي.

## جديد v1.0.1

- عملية خادمية جديدة: `analyze_primary`.
- عقد تحليل جديد: `6.0.0`.
- فصل الحقيقة والاستنتاج والفرضية عبر `claimType`.
- أعداد التشخيصات والاستنتاجات والتدخلات غير ثابتة؛ يحددها الدليل والسياق.
- كل تشغيل يطلب قراءة تحليلية جديدة، ولا يعيد نتيجة تربوية مخزنة لمجرد تطابق الملف.
- الحسابات والرسوم تبقى محمية ولا يحق للنموذج تغييرها.
- التقرير الرسمي لا يُنشأ إلا من تحليل ذكاء اصطناعي مكتمل ومتحقق.

## التحقق المحلي

```bash
npm run check
```

يشغل اختبارات عقد التحليل الذكي، التقرير الرسمي، بوصلة الإتقان، المحللات الحسابية، سلامة JavaScript، ومراجع ملفات الموقع.

## النشر

1. ارفع ملفات الواجهة إلى مستودع GitHub Pages.
2. استبدل كود وظيفة Supabase `analyze-educational-form` بمحتوى:

```text
SUPABASE_FUNCTION_GEMINI_V0_13_0.txt
```

3. أعد نشر وظيفة Edge.
4. لا يلزم SQL جديد ولا سر جديد. يبقى `GEMINI_API_KEY` والضبط السابق كما هما.
5. نفّذ اختبارًا حيًا بملف حقيقي، لأن بيئة التجهيز لا تملك اتصال Gemini/Supabase الخاص بالمشروع.
