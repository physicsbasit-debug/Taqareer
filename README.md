# تقارير v0.2.0

هذه الحزمة تمثل **Phase 1-A1: نواة استقبال البيانات والتحليل الوصفي الأولي**.

## ما يعمل فعليًا

- قراءة CSV وTSV وTXT الجدولي داخل المتصفح.
- لصق الجداول مباشرة من Excel.
- معاينة البيانات واكتشاف الأعمدة والسجلات.
- تعرف أولي على عائلات الاستمارات الحالية ونوع جديد غير مسجل.
- فحص القيم المفقودة والتكرارات مع منع محدود للحالات الحرجة فقط.
- تحليل وصفي للدرجات: المتوسط والوسيط والمدى والانحراف المعياري.
- حساب الإتقان بعد تأكيد الدرجة الكلية وحد الإتقان.
- تحليل توزيع مستويات الأداء.
- استنتاجات محلية مرتبطة بأدلة وحدود واضحة.
- طباعة النتائج وتصدير JSON.
- نشر تلقائي على GitHub Pages.

## غير مفعّل بعد

- قراءة XLSX الأصلية.
- استخراج PDF وWord والصور.
- ربط نموذج ذكاء اصطناعي حي.
- حفظ المشاريع في قاعدة بيانات.

## تشغيل محلي

افتح `index.html` مباشرة، أو شغّل خادمًا محليًا:

```bash
python -m http.server 8080
```

ثم افتح `http://localhost:8080`.

## الملفات المخفية

تحتوي الحزمة على المسار الحقيقي:

```text
.github/workflows/deploy.yml
```

وتحتوي أيضًا على نسخة مرئية احتياطية:

```text
GITHUB_WORKFLOW_VISIBLE/deploy.yml
```

إذا اختفى مجلد `.github` عند الرفع من الهاتف، أنشئ الملف داخل GitHub بالمسار الكامل وانسخ محتوى النسخة المرئية. لا تحتاج إلى إنشاء `.nojekyll` يدويًا، لأن workflow ينشئه داخل حزمة النشر.
