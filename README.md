# تقارير v1.1.4

## Phase 2-C Fix 4 — Multi-Visit Sample Scope Guard

يحافظ الإصدار على محرك الزيارات الإشرافية المتعددة، والمقياس المعكوس، والرسوم، والخصوصية، ومهلة Gemini المنسقة. ويضيف حارس نطاق ثنائيًا يمنع تعميم تدخلات عينة قسم أو مواد محددة على جميع معلمي المدرسة.

### الجديد
- إنشاء `scopeContext` محلي من المواد والصفوف وعدد الزيارات والمدرسة.
- تمرير نطاق العينة إلى Gemini بوضوح.
- تضييق أي فئة مستهدفة واسعة مثل «الهيئة التدريسية» إلى الفئة الفعلية، مثل «معلمو قسم العلوم المشمولون بالزيارات».
- إبقاء الفئات الأضيق المدعومة، مثل «معلمو مادة العلوم للصف الثامن».
- إعادة تحقق مستقلة في المتصفح من عدد الزيارات واسم الفئة النهائية.
- تسجيل `scopeGuard.adjusted` وسبب التعديل لأغراض المراجعة.
