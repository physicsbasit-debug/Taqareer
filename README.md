# تقارير v1.2.3

منصة تحليل تربوي تكيفية تعمل على GitHub Pages، مع Supabase Edge Function لربط Gemini بوصفه المحلل التربوي الأساسي، بينما تبقى القراءة والحسابات والرسوم والتحقق العددي محلية المصدر.

## Phase 2-D Fix 3 — Reliable Workbook Intake & Subject Selector

يعالج هذا الإصدار مشكلة ظهور مساحة تحليل النتائج متعددة المواد مع قائمة مادة فارغة. أصبح قارئ Excel:

- يقرأ ملفات OOXML سواء استخدمت الوسوم القياسية أو وسوم XML ذات بادئة namespace.
- يكتشف أزواج المستوى والدرجة مهما بدأت في يمين الورقة أو يسارها، وباتجاه `المستوى-الدرجة` أو `الدرجة-المستوى`.
- يبحث عن حقول الاسم والرقم والقيد والجنسية على جانبي كتلة المواد بدل افتراض موضع واحد.
- يمرر نوع الورقة وبيانات الصف والفترة والمواد كاملة إلى واجهة التحليل.
- يختار ورقة النتائج الشاملة تلقائيًا عندما تكون أوضح بكثير من أوراق الشعب.
- يستعيد قائمة المواد من الملف الدلالي أو بيانات الورقة أو أسماء الأعمدة، مع منع التنفيذ إذا بقيت البنية ناقصة.
- يضيف بصمة إصدار إلى ملفات JavaScript وCSS لمنع خلط واجهة جديدة بقارئ قديم محفوظ في ذاكرة المتصفح.
