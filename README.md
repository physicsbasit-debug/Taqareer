# تقارير v0.8.2

منصة عربية للتحليل التربوي التكيفي العميق للملفات والاستمارات التعليمية.

## الجديد في v0.8.2

- فصل ظهور الحسابات والرسوم المحلية عن انتظار Gemini؛ تظهر النتائج الحتمية فورًا ثم يصل التفسير الذكي لاحقًا.
- تقليل حمولة ملفات الدرجات المرسلة إلى Gemini: يعتمد النموذج على المؤشرات والرسوم المحسوبة من كامل البيانات، مع عينة سياقية صغيرة فقط.
- عدم استدعاء Gemini للتصنيف عندما يكون النوع المحلي المعروف بثقة 95% فأكثر.
- استخدام ذاكرة مؤقتة محلية آمنة لإعادة نتيجة التحليل الذكي عند تحليل الملف نفسه بالإعدادات نفسها.
- زر مستقل لإعادة التفسير الذكي فقط عند فشل الاتصال، دون إعادة قراءة الملف أو حساب المؤشرات والرسوم.
- عرض زمن الحساب المحلي وزمن Gemini وحجم الحمولة والزمن الكلي للمستخدم.
- استخدام `gemini-2.5-flash-lite` افتراضيًا للتصنيف السريع، مع إبقاء `gemini-2.5-flash` للتحليل العميق.
- ضبط ميزانية التفكير: صفر للتصنيف والقراءة الاستخراجية، و1024 للتحليل التربوي العميق.
- لا تغيير في معادلات بوصلة الإتقان أو الرسوم أو أدوات الجودة أو تصميم التقرير الرسمي.
