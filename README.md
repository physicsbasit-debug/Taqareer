# Phase 0-B2 — عقود التحليل وعمارة الذكاء الاصطناعي

هذه الحزمة توثّق النواة التحليلية لمنصة ذكية تفهم الاستمارات والتقارير التربوية متعددة الصيغ، وتتعرف على نوعها، وتبني خطة تحليل متخصصة، ثم تنتج استنتاجات وتوصيات مرتبطة بالأدلة.

## المبادئ الحاكمة

1. **النوع غير مغلق:** النماذج الحالية أمثلة أولية، ويمكن تعريف أنواع جديدة دون تعديل قلب النظام.
2. **الذكاء الاصطناعي مركزي:** يفهم الملف، يصنفه، يبني خطة التحليل، يحلل النصوص، ويصوغ الاستنتاجات والتوصيات.
3. **الحسابات حتمية:** الإحصاءات، التحقق من القيم، المطابقة، والنسب تنفذ برمجيًا ويمكن مراجعتها.
4. **كل استنتاج له دليل:** لا يعتمد أي استنتاج دون مرجع واضح للجدول أو السجل أو العبارة المصدرية.
5. **المستخدم يرى البساطة:** ارفع، راجع، حلل، اعتمد، صدّر. أما التعقيد فيبقى خلف الواجهة.
6. **المراجعة البشرية إلزامية:** الاستنتاجات والتوصيات الآلية لا تصبح معتمدة قبل مراجعة المستخدم المخول.

## النماذج المرجعية المستخدمة

- `CrystalReportViewer1-2.pdf`: ملخص مؤشرات الزيارة الإشرافية.
- `CrystalReportViewer1-1(2).pdf`: تقرير إشرافي سردي يتضمن الإجادة، التطوير، الدعم والتوصيات.
- `CrystalReportViewer1(1).pdf`: ملخص فحص أعمال الطلبة.
- `CrystalReportViewer1-3.pdf`: توزيع مستويات الطلبة.
- `CrystalReportViewer1-4.pdf`: نتائج الطلبة في مادة واحدة.
- `PDF_SearchReportXSD_28202603151717.XSD.PDF`: درجات اختبار نهاية الفصل.
- `PDF_SearchReportXSD_28202603239179.XSD.PDF`: درجات التقويم المستمر.
- `CrystalReportViewer1-5.pdf`: نتائج الطلبة عبر مواد متعددة.
