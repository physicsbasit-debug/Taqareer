# تقارير v0.4.0

## Phase 1-A3: استقبال المستندات والتحليل السردي

تحول هذه النسخة «تقارير» من قارئ جداول فقط إلى نواة استقبال متعددة الصيغ. أصبح التطبيق يقرأ ملفات Word الحديثة، ويستخرج النصوص والجداول من ملفات PDF ذات الطبقة النصية، ويحلل التقارير السردية تربويًا بصورة أولية وقابلة للمراجعة.

## ما يعمل فعليًا

- CSV وTSV وTXT الجدولي.
- Excel بصيغتي XLSX وXLSM، مع اختيار ورقة العمل واكتشاف صف العناوين.
- Word DOCX: قراءة الجداول والفقرات محليًا من بنية OOXML داخل المتصفح.
- PDF النصي: تحميل PDF.js عند فتح الملف، واستخراج الأسطر والجداول المحتملة والنص الكامل.
- الصور: معاينة محلية وإدخال النص أو الجدول يدويًا مؤقتًا.
- مسار احتياطي لملفات PDF الممسوحة أو ضعيفة الطبقة النصية بدل إيقاف العمل.
- تحليل رقمي للدرجات والمستويات.
- تحليل سردي أولي يشمل الموضوعات التربوية، مؤشرات الأدلة، جوانب التطوير، والتوصيات.
- تصدير JSON والطباعة.

## القيود الحالية

- يحتاج استخراج PDF النصي إلى اتصال بالإنترنت عند أول استخدام لتحميل PDF.js المثبت على الإصدار 6.2.108.
- OCR التلقائي للصور وPDF الممسوح غير مفعّل بعد.
- تحليل النص الحالي محلي وقائم على قواعد لغوية تربوية، وليس اتصالًا حيًا بنموذج ذكاء اصطناعي.
- DOC وXLS القديمان وملفات Crystal Reports الأصلية RPT غير مدعومة مباشرة.

## الملف المناسب للرفع

للتحديث فوق مستودع v0.3.0 استخدم حزمة `changed_files_only`. لا تحتوي هذه الحزمة على `.github` ولا على النسخة المرئية الاحتياطية، ولذلك لن تكرر مجلد التشغيل الموجود لديك.

النسخة الكاملة `full_backup` للحفظ أو إنشاء مستودع جديد فقط، وتحتوي على المسار الحقيقي `.github/workflows/deploy.yml` والنسخة المرئية الاحتياطية وفق قاعدة المشروع.
