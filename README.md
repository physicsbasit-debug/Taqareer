# تقارير v0.6.1

## Phase 1-B2 Fix 1: التقرير الرسمي المكثف بصريًا

يعالج هذا الإصدار مشكلة المساحات البيضاء والصفحات الفارغة من جذورها. لم يعد التقرير يعتمد صفحات ثابتة الارتفاع، بل يختار تلقائيًا تخطيطًا من صفحة واحدة أو صفحتين بحسب حجم المحتوى.

### أبرز التحسينات
- إلغاء الارتفاع الثابت A4 الذي كان يولّد صفحات بيضاء.
- دمج الاستنتاجات وخطة التحسين في صفحة واحدة عند قلة المحتوى.
- ضغط المسافات دون التضحية بالوضوح.
- عنوان رسمي مختصر مع إبقاء عنوان المصدر في سطر ثانوي.
- عرض الإجراء الواحد كبطاقة قرار بدل جدول ضخم.
- إخفاء قسم أدوات الجودة إذا لم توجد أداة معتمدة.
- تكبير النصوص الصغيرة نسبيًا مع تحسين التباين.
- عدم الحاجة إلى أي تعديل في Supabase أو Gemini.

ارفع محتويات حزمة changed-files-only فوق المستودع الحالي.
