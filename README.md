# تقارير v0.8.1

منصة عربية بسيطة للتحليل التربوي التكيفي العميق للملفات والاستمارات التعليمية.

## الجديد في v0.8.1

- إصلاح جذري لاختفاء فئات من الرسوم في الصفحة الأولى للتقرير.
- عرض نطاقات الدرجات العشرة كاملة دون قص: من `0-4` حتى `36-40`.
- عرض فئات التدخل الأربع كاملة، بما فيها فئة الفجوة العميقة.
- إضافة عقد تحقق يمنع إنشاء التقرير إذا لم يساو مجموع فئات الرسم عدد السجلات الصالحة.
- إضافة تخطيط كثيف تلقائي للرسوم ذات الفئات الكثيرة دون حذف البيانات أو تصغير النص إلى حد غير مقروء.
- إضافة فحص بصري داخل التقرير يرصد اختلاف عدد الصفوف أو خروج آخر صف عن حدود البطاقة.
- الحفاظ على عقد بوصلة الإتقان v0.8.0 دون أي تغيير في المعادلات أو الأحكام.
- لا يلزم تعديل Supabase أو Gemini أو SQL أو Edge Function.
