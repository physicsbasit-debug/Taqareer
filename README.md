# تقارير v1.0.4

تطبيق لتحليل الاستمارات والبيانات التربوية، يفصل بين **الحساب الموثوق** و**التحليل الذكي**:

- المتصفح يقرأ الملفات ويحسب المؤشرات والرسوم ومراجع الأدلة.
- Gemini هو المحلل التربوي الأساسي.
- بوابات التحقق تمنع الأرقام والمراجع المختلقة والنتائج الناقصة.
- لا تُعرض قوالب محلية محفوظة بوصفها تحليلًا عميقًا.

## جديد Phase 2-B

- عقد `6.3.0` يفصل بين القراءة التشخيصية والاستنتاج القراري.
- 3 محاور تحليلية في المسار الطبيعي.
- 2–3 تدخلات متمايزة، وثلاث مراحل متابعة.
- أداة جودة واحدة على الأقل في المسار الطبيعي.
- منع تسمية مهارة أو مفهوم من درجات كلية بلا دليل مفردات.
- الإبقاء على التفكير المضبوط ومسار الإنقاذ من `v1.0.3`.

## التحقق المحلي

```bash
npm run check
```

## النشر

1. ارفع ملفات الحزمة إلى GitHub.
2. استبدل كود وظيفة Supabase بمحتوى `SUPABASE_FUNCTION_GEMINI_V0_13_4.txt`.
3. أعد نشر وظيفة Edge.
4. لا SQL جديد ولا سر جديد.
5. اختبر الملف نفسه حيًا.
