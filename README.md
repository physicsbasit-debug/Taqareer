# تقارير v0.9.1

منصة عربية للتحليل التربوي التكيفي العميق للملفات والاستمارات التعليمية.

## Phase 1-C3 Fix 1: Deep Analysis Delta Protocol

يعالج هذا الإصدار فشل Gemini عند إرجاع عقد JSON ضخم، من دون تقليل دوره إلى تحسين لغوي. أصبح التقسيم المعماري واضحًا:

```text
المحرك المتخصص المحلي
= الحسابات، الأدلة، الرسوم، البنية الرسمية، وأدوات الجودة المشروطة

Gemini
= التفسير التربوي العميق، البدائل التفسيرية، حدود الاستدلال، البيانات المطلوبة، وتحسين التنفيذ

محرك المصالحة
= التحقق من الأدلة والمعرفات، تطبيق التحسينات، ومنع تغيير الحسابات أو إنشاء خطط موازية
```

### البروتوكول الجديد

- يعيد Gemini وحدات `deepAnalysisUnits` كاملة للقراءات التشخيصية، وليس جملًا تجميلية قصيرة.
- يعيد `patches` حقلية صغيرة لتحسين الأثر والإجراء والتنفيذ والمتابعة.
- لا يستطيع Gemini تغيير الأعداد أو النسب أو الفئات أو عدد التدخلات.
- عند توقف الرد بسبب `MAX_TOKENS` أو JSON غير مكتمل، تنفذ الوظيفة محاولة دلالية مختصرة واحدة فقط.
- نتيجة الفشل لا تمحو التحليل المحلي ولا تحفظ في الذاكرة المؤقتة.
- تختلف محاور Gemini باختلاف نوع الاستمارة؛ التقرير الإشرافي لا يستخدم إجراءات تحليل الدرجات.
