# تقارير v1.0.6

تطبيق لتحليل الاستمارات والبيانات التربوية، يفصل بين **الحساب الموثوق** و**التحليل الذكي**:

- المتصفح يقرأ الملفات ويحسب المؤشرات والرسوم ومراجع الأدلة.
- Gemini هو المحلل التربوي الأساسي.
- بوابات التحقق تمنع الأرقام والمراجع المختلقة والنتائج الناقصة.
- لا تُعرض قوالب محلية محفوظة بوصفها تحليلًا عميقًا.

## جديد Phase 2-B Fix 2

- استخراج بيانات ترويسة Word من `header/footer` بدل الاعتماد على متن المستند فقط.
- تمرير المدرسة والمادة والصفوف والعام الدراسي والتاريخ والمحافظة ورمز المدرسة إلى التقرير الرسمي.
- توحيد اتجاه العام الدراسي الناتج من RTL مع الاحتفاظ بالقيمة الخام.
- تصنيف العبارات المتعارضة في التقارير التجميعية كتباين سياقي يحتاج فصل السجلات، لا تناقض مؤكد تلقائيًا.
- توجيه Gemini إلى عدم نسب جميع الممارسات إلى معلم واحد عند غياب معرف المعلم أو الزيارة.
- بقيت مكتسبات `v1.0.5`: الحارس العددي، العمق المتوازن، التفكير المضبوط، ومسار الإنقاذ.
