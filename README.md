# تقارير v0.9.2

منصة عربية للتحليل التربوي التكيفي العميق للملفات والاستمارات التعليمية.

## Phase 1-C3 Fix 2: Segmented Deep Analysis Pipeline

يعالج هذا الإصدار السبب الجذري لفشل Gemini عند محاولة إعادة تحليل تربوي عميق كامل داخل استجابة JSON واحدة. لم يُختزل دور Gemini، بل قُسم إلى أربعة أجزاء تربوية محددة تعمل بصورة مستقلة:

```text
المحرك المتخصص المحلي
= الحسابات، الأدلة، الرسوم، بنية الاستنتاجات والتدخلات والمتابعة

Gemini المقسّم
= التشخيص العميق + تعميق الاستنتاجات + تحسين التدخلات + الجودة والمتابعة

محرك المصالحة
= دمج كل جزء ناجح فور وصوله، منع تغيير الحسابات، ومنع التكرار
```

### الأجزاء الأربعة

1. `diagnostic` - القراءة التشخيصية، التفسيرات البديلة، الحدود، والبيانات المطلوبة.
2. `findings` - تعميق الاستنتاجات والأثر التربوي والإجراء المرتبط.
3. `interventions` - تحسين خطوات التنفيذ والموارد والمسؤول والزمن والمؤشر والخطة البديلة.
4. `governance` - تحسين أدوات الجودة ومراحل المتابعة وضوابط القرار.

### السلوك التشغيلي

- تظهر الحسابات والرسوم المحلية فورًا.
- تعمل أجزاء Gemini الأربعة بالتوازي.
- يُدمج كل جزء ناجح فور وصوله دون انتظار البقية.
- إذا فشل جزء واحد، تبقى النتائج المحلية وبقية الأجزاء الناجحة.
- زر الإعادة يعيد الجزء المتعثر فقط.
- لكل جزء ذاكرة مؤقتة وبصمة وقياس زمن مستقلان.
- لا يستطيع Gemini إنشاء تدخل خامس أو دورة متابعة موازية أو تعديل معادلات بوصلة الإتقان.
