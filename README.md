# تقارير v0.5.1

## Phase 1-B1 Fix 1: تطبيع ملفات الوزارة والتعرف الهجين

تعالج هذه النسخة السبب الجذري لسوء قراءة ملفات Excel الصادرة من الأنظمة الوزارية. هذه الملفات تكون عادةً مصممة للطباعة، وقد تحتوي على خلايا مدمجة، وصفوف وأعمدة فاصلة صغيرة، وعناوين متعددة المستويات، وبيانات تمهيدية فوق الجدول. لذلك لم يعد «تقارير» يتعامل مع كل خلية ظاهرة على أنها حقل تحليلي.

## ما تغير

- إضافة **محرك تطبيع ملفات Excel الوزارية** قبل التصنيف والتحليل.
- اكتشاف صف أو نطاق العناوين الحقيقي بدل افتراض الصف الأول.
- فهم الخلايا المدمجة وإعادة بنائها كحقول منطقية.
- حذف الصفوف والأعمدة الطباعية الفاصلة دون مطالبة المستخدم بتنظيف الملف يدويًا.
- فصل عنوان التقرير وبياناته التمهيدية عن جدول السجلات.
- إعادة ترتيب الحقول العربية وفق ترتيب منطقي عند الحاجة.
- حساب اكتمال الحقول الأساسية فقط؛ الحقول الاختيارية الفارغة مثل «ملاحظات» لا تخفض جودة الملف.
- إصلاح تصنيف التقارير السردية، وعدم اعتبار الحروف أ/ب/ج داخل النص أعمدة مستويات أداء.
- إضافة تحقق دلالي اختياري بواسطة Gemini في مرحلة فهم نوع النموذج، مع استمرار التصنيف المحلي عند تعذر الاتصال.
- إظهار مصدر التصنيف وسبب اختياره للمستخدم.

## الرفع فوق المستودع الحالي

استخدم حزمة `changed_files_only`. لا تحتوي على `.github` أو `.nojekyll`، ولذلك لا تمس ملف النشر الذي أنشأته يدويًا.

بعد رفع ملفات الواجهة، يجب أيضًا تحديث كود وظيفة Supabase من الملف:

`supabase/functions/analyze-educational-form/index.ts`

ثم الضغط على **Deploy function**. لا يلزم تغيير الأسرار الحالية.
