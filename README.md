# تقارير v0.3.0

تمثل هذه الحزمة **Phase 1-A2: قراءة Excel الفعلية واكتشاف الجداول**.

## ما يعمل فعليًا

- قراءة CSV وTSV وTXT الجدولي داخل المتصفح.
- قراءة ملفات Excel الحديثة بصيغتي XLSX وXLSM محليًا دون رفعها إلى خادم.
- اكتشاف أوراق العمل التي تحتوي جداول واضحة.
- اختيار ورقة العمل عند وجود أكثر من جدول صالح.
- اكتشاف صف العناوين حتى عند وجود عنوان تقرير أو صفوف فارغة قبله.
- معاينة الأعمدة والسجلات قبل التحليل.
- التعرف الأولي على الأنواع الحالية أو نوع جديد غير مسجل.
- فحص القيم المفقودة والتكرارات مع منع محدود للحالات الحرجة فقط.
- التحليل الوصفي للدرجات وتوزيع المستويات وحساب الإتقان بعد تأكيد الدرجة الكلية.
- طباعة النتائج وتصدير JSON يتضمن اسم ملف Excel وورقة العمل وصف العناوين المكتشف.

## حدود دعم Excel الحالية

- تعمل XLSX وXLSM.
- صيغة XLS القديمة تحتاج حفظًا بصيغة XLSX أو CSV.
- يدعم المحرك الجداول المعتادة والخلايا النصية والرقمية والتواريخ الأساسية.
- لا يحلل الصيغ المعقدة نفسها، لكنه يقرأ القيمة المحفوظة داخل الخلية عند توفرها.
- إذا احتوت الورقة عدة جداول منفصلة، يختار المحرك الجدول الأوضح حاليًا. دعم الجداول المتعددة داخل الورقة نفسها يأتي لاحقًا.

## غير مفعّل بعد

- استخراج PDF وWord والصور.
- الذكاء الاصطناعي الحي.
- الحفظ السحابي وحسابات المستخدمين.
- استيراد XLS القديم مباشرة.

## التشغيل المحلي

افتح `index.html` مباشرة، أو شغّل:

```bash
python -m http.server 8080
```

ثم افتح `http://localhost:8080`.

## ملفات GitHub المخفية

المسار الحقيقي المستخدم في المستودع:

```text
.github/workflows/deploy.yml
```

توجد نسخة مرئية احتياطية في:

```text
GITHUB_WORKFLOW_VISIBLE/deploy.yml
```

هذه النسخة الاحتياطية **لا تُرفع إلى المستودع** إذا كان مسار `.github` موجودًا بالفعل. ملف التشغيل ينشئ `.nojekyll` تلقائيًا.
