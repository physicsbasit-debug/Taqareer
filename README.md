# تقارير v1.2.2

منصة تحليل تربوي تكيفية تعمل على GitHub Pages، مع Supabase Edge Function لربط Gemini بوصفه المحلل التربوي الأساسي، بينما تبقى القراءة والحسابات والرسوم والتحقق العددي محلية المصدر.

## Phase 2-D Fix 2 — مساحة تحليل النتائج متعددة المواد ومحرك الترتيب

يضيف هذا الإصدار لمسار `multi_subject_results`:

- اختيار تحليل شامل لجميع المواد أو تحليل مادة محددة.
- استخراج العشرة الأوائل في كل مادة محليًا.
- ترتيب العشرة الأوائل على مستوى المدرسة/الدفعة وفق المعادلات المعتمدة للصفوف 5–12.
- ترتيب منافسة قياسي بلا كسر تعادل: الأول مكرر ثم الثالث.
- استبعاد الطالب ناقص المادة الأساسية من الترتيب مع وسم «غير مكتمل للترتيب».
- فصل التصنيفات الأساسية المتبادلة عن المؤشرات الثانوية المتداخلة.
- إظهار الصف والعام والفترة ونطاق المادة في التقرير الرسمي.
- إبقاء أسماء الطلبة داخل المتصفح والتقرير المحلي فقط، دون إرسالها إلى Gemini.

## معادلات ترتيب المدرسة/الدفعة

- الصفوف 5–9: `70% متوسط المواد الأساسية + 30% متوسط جميع المواد`.

المواد الأساسية للصفوف 9–12: العربية، التربية الإسلامية، الدراسات الاجتماعية، الرياضيات، الإنجليزية، الفيزياء، الكيمياء، والأحياء.
