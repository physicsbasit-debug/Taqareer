# تقارير v0.9.0

منصة عربية للتحليل التربوي التكيفي العميق للملفات والاستمارات التعليمية.

## ما الذي أعيد بناؤه في v0.9.0؟

أُلغي مسار جمع تقرير المحرك المحلي مع تقرير Gemini. أصبح المحرك الحتمي يبني **عقد التحليل الرسمي الوحيد**، ثم يعيد Gemini تحسينات مركزة `Delta` مرتبطة بمعرفات ثابتة داخل العقد.

المسار الجديد:

```text
التحليل الحتمي المتخصص
→ عقد رسمي بمعرفات ثابتة
→ Gemini Delta لتحسين حقول محددة
→ تحقق خادمي من المعرفات والأدلة
→ مصالحة على مستوى الحقول
→ نموذج تحليل واحد للتطبيق والتقرير
```

### النتيجة في تحليل الدرجات

- 5 استنتاجات فقط، لا نسخة محلية ونسخة ذكية.
- 4 تدخلات فقط: فجوة عميقة، فجوة متوسطة، قريب من الإتقان، تثبيت وإثراء.
- 4 مراحل متابعة فقط.
- الحسابات والفئات وأعداد الطلبة مقفلة للمحرك الحتمي ولا يستطيع Gemini تغييرها.
- المعرفات غير الموجودة ومراجع الأدلة غير الصالحة تُرفض.
- التقرير الرسمي يقرأ النموذج المصالَح نفسه الذي تعرضه الواجهة.

## تحديث Supabase مطلوب

استبدل كود وظيفة `analyze-educational-form` بمحتوى:

`SUPABASE_FUNCTION_GEMINI_V0_7_0.txt`

ثم اضغط `Deploy function`.

لا توجد أسرار أو SQL أو جداول جديدة.

## التوافق

أُبقيت العملية القديمة `analyze` للتوافق مع نسخ أقدم، لكن الواجهة الحالية تستخدم العملية الجديدة `enrich` فقط.
