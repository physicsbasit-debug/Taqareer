# تقارير v1.2.5

منصة تحليل تربوي تكيفية تعمل على GitHub Pages، مع Supabase Edge Function لربط Gemini بوصفه المحلل التربوي الأساسي، بينما تبقى القراءة والحسابات والترتيب والرسوم والتحقق العددي محلية المصدر.

## Phase 2-D Fix 5 — Executive & Full Reports + Level Provenance Guard

يضيف هذا الإصدار نمطين رسميين للتقرير في نتائج الطلاب متعددة المواد:

- **التقرير التنفيذي المختصر**: يحتفظ بالملخص والمؤشرات والقراءة التشخيصية وخطة التدخل والمتابعة، ويعرض ترتيب المدرسة أو المادة المناسبة دون إغراق التقرير بجميع ملاحق أوائل المواد.
- **التقرير الكامل مع الجداول**: يحافظ على جميع صفحات التحليل وجداول العشرة الأوائل لكل مادة، بما في ذلك جميع المتعادلين في المركز العاشر.

كما يشدد الإصدار سياسة مصدر المستويات:

- إذا احتوى ملف Excel على درجة ومستوى مستقلين، يبقى فحص اتساق الدرجة والمستوى ظاهرًا وصحيحًا.
- إذا احتوى الملف على درجات فقط، تُشتق المستويات محليًا وتظهر حدود الاشتقاق بدل ادعاء مقارنة مصدرين مستقلين.
- يمنع حارس المصالحة أي صياغة آلية توحي بوجود فحص اتساق مستقل في ملفات المستويات المشتقة.

## تحليل النتائج متعددة المواد

يدعم التطبيق:

- التحليل الشامل لجميع المواد أو تحليل مادة محددة.
- العشرة الأوائل في كل مادة.
- ترتيب المدرسة أو الدفعة وفق المعادلات المعتمدة.
- ترتيب المنافسة القياسي دون كسر التعادل.
- استبعاد الطالب غير مكتمل المواد الأساسية من ترتيب المدرسة.
- إبقاء الأسماء والجنسية محليًا وعدم إرسالهما إلى Gemini.
