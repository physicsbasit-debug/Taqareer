# تقارير v1.2.0

> Phase 2-D: Adaptive Semantic Analysis Router

«تقارير» لا يفرض طريقة تحليل واحدة على كل ملف. عند رفع البيانات يبني أولًا **ملفًا دلاليًا للبنية** يحدد وحدة التحليل، مستوى التجميع، الأعمدة البعدية والعددية، اتجاه المقياس، صفوف الإجماليات، وعائلات التحليل المناسبة. يتحقق Gemini من المعنى دلاليًا، بينما تبقى القراءة المحلية والحسابات مصدر الحقيقة البنيوية والعددية.

## ما تغير في v1.2.0

- تحقق Gemini الدلالي يعمل مع كل ملف عند توفر الاتصال، لا عند انخفاض الثقة فقط.
- إعدادات التحليل تظهر وفق طبيعة الملف؛ ملفات التوزيع المجمع لا تطلب عمود درجة أو درجة كلية أو حد إتقان.
- التوجيه إلى المحلل يعتمد على `semanticProfile` والقدرات المطلوبة، لا على اسم النوع وحده.
- يمكن إنشاء نوع تكيفي مؤقت في وقت التشغيل إذا لم يطابق الملف نوعًا معروفًا.
- صفوف الإجماليات تُستبعد من التجميع لمنع العد المزدوج، ثم تستخدم لفحص اتساق المجاميع والنسب.
- أضيف دعم بنيوي لكشوف مستويات الأداء الناتجة من Crystal Reports بعد حفظها بصيغة `.xlsx`.

## الاختبار المرجعي

كشف الصف التاسع للفيزياء:

- 8 شعب + صف إجمالي.
- 5 مستويات أداء: أ، ب، ج، د، هـ.
- 267 طالبًا، و266 ناجحًا، ونسبة نجاح 99.63%.
- لا تظهر إعدادات الدرجات الفردية.
- لا يُحتسب صف الإجمالي مرتين.
