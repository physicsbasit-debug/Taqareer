# تقارير v0.9.3

منصة عربية للتحليل التربوي التكيفي العميق للملفات والاستمارات التعليمية.

## Phase 1-C3: Automatic Segment Recovery Manager

يعالج هذا الإصدار آخر عيب تشغيلي في خط التحليل المقسّم: اضطرار المستخدم إلى الضغط المتكرر على زر إعادة الأجزاء المتعثرة. أصبح المنسق يستعيد الأجزاء ذات الأخطاء المؤقتة تلقائيًا، مع إبقاء الأجزاء الناجحة والحسابات والرسوم دون إعادة.

### السلوك الجديد

- تعمل أجزاء Gemini الأربعة بالتوازي كما في v0.9.2.
- عند تعثر جزء مؤقتًا، ينتظر المنسق فترة قصيرة ثم يعيد **ذلك الجزء فقط** تلقائيًا.
- ينفذ جولتي استعادة آليتين بحد أقصى بعد الطلب الأول.
- تستخدم الاستعادة تأخيرًا تدريجيًا مع jitter وتلتزم بـ `Retry-After` إن أرسله الخادم.
- لا تعاد الأجزاء الناجحة ولا الحسابات ولا الرسوم.
- لا تعاد أخطاء الإعدادات غير القابلة للاستعادة، مثل رمز الوصول غير الصحيح أو النطاق غير المسموح.
- لا يظهر زر الإعادة اليدوية إلا بعد استنفاد الاستعادة الآلية أو وجود خطأ غير قابل للإعادة.
- تظهر حالة الاستعادة والجزء الجاري استعادته، ثم يوضح التقرير التشغيلي عدد الأجزاء التي استعيدت تلقائيًا.
