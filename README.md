# تقارير

منصة تحليل تربوي للدرجات والاستبانات والزيارات والبيانات التعليمية. الواجهة تعمل كموقع ثابت على GitHub Pages، بينما تبقى العمليات الحساسة والتحليل الخارجي في Supabase Edge Function.

## الحالة التشغيلية الحالية

- التطبيق: `v1.2.22`
- تخطيط التقرير: Cross-Section A4 Flow يستغل المساحة المتبقية بين الأقسام دون تصغير الخط أو كسر البطاقات.
- Supabase Edge: `V0.15.4`
- عقد التحليل: `6.6.0`
- Semantic Profile: `2.1.0`
- المصدر التشغيلي لوظيفة التحليل: `supabase/functions/analyze-educational-form/index.ts`
- Fix 16: محرك رسوم دلالي مشترك يختار شكل الرسم من الغرض التحليلي والبيانات، ويعمل على جميع أنواع التقارير بدل ربط كل تقرير بنوع رسم ثابت.
- سياسة الرسوم المشتركة تدعم حاليًا: Bar, Histogram, 100% Stacked, Line, Radar, Bullet, Dumbbell, Scatter, Pareto, Box, Heatmap, Table.

لا تُحفظ نسخ نصية متسلسلة من Edge Function في جذر المستودع. تاريخ Git هو الأرشيف الرسمي للإصدارات القديمة.

## بنية المستودع

```text
.github/        GitHub Actions وGitHub Pages
assets/         ملفات الواجهة ومحركات التحليل المحلية
scripts/        فحوص المشروع وصيانة المستودع
tests/          الاختبارات النشطة وFixtures اللازمة لها
supabase/       المصدر الحالي لوظائف Supabase
src-contracts/  عقود TypeScript المرجعية
docs/           الوثائق المعمارية الحالية
samples/        عينات تعليمية واختبارية
registry/       سجل أنواع الاستمارات
index.html      نقطة تشغيل الواجهة
manifest.json   عقد الإصدار والخصائص
```

## الفحص قبل أي رفع

```bash
npm ci
npm run check
```

يشمل الفحص:

- الاختبارات النشطة.
- سلامة JavaScript.
- عقود التحليل.
- مراجع الموقع الثابت.
- حارس نظافة المستودع لمنع عودة ملفات المراحل والحزم القديمة.

## سياسة المستودع

يبقى `main` للكود الحالي والاختبارات الحالية والوثائق الحالية فقط. ملفات الحزم المرحلية مثل `APPLY_*` و`TEST_REPORT_PHASE_*` و`CHANGED_FILES_MANIFEST*` ونسخ `SUPABASE_FUNCTION_GEMINI_V*.txt` تُحفظ خارج المستودع داخل حزم التسليم فقط.

## النشر

راجع `docs/DEPLOYMENT.md` للتفاصيل. GitHub Pages ينشر ملفات التشغيل العامة فقط (`index.html` و`manifest.json` و`assets/`) ولا ينشر وثائق التطوير أو العينات أو ملفات الخادم.
