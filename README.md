# تقارير v0.7.0

## Phase 1-C1: محرك التحليل التربوي التكيفي العميق

هذا الإصدار يعيد بناء عقل التحليل من الجذور. لا توجد طريقة تحليل موحدة تُلبس لكل الاستمارات؛ توجد بنية مشتركة للاستقبال والتنظيف والتحقق والأدلة فقط، ثم يوجّه كل نوع إلى محلل تربوي متخصص بمؤشراته ورسومه وأدوات جودته وخطته.

## المحللات المتخصصة

1. نتائج مادة واحدة.
2. درجات مكوّن تقويمي.
3. توزيع مستويات الأداء.
4. الأداء عبر المواد.
5. مؤشرات الزيارة الإشرافية.
6. فحص أعمال الطلبة.
7. التقرير الإشرافي السردي.
8. استبانات الاتجاهات والرضا.
9. الاحتياجات التدريبية.
10. تقييم البرامج والمبادرات.
11. السلوك والغياب والانضباط.
12. نوع جديد: محلل تكيفي يبني ملفًا تحليليًا وعقدًا مقترحًا من بنية البيانات، ولا يحشره في أقرب قالب معروف.

## ماذا ينتج كل محلل؟

- ملف منهجي يوضح كفاية البيانات والقرارات التي يمكن دعمها.
- مؤشرات كمية أو نوعية تناسب النوع نفسه.
- رسوم بيانية مختارة بشرط أن تضيف معنى.
- قراءات تشخيصية عميقة، لا خلاصة مكررة.
- استنتاجات مرتبطة بالأدلة ودرجة الثقة والحدود.
- أدوات جودة مطبقة مع تفسير ناتجها، لا مجرد أسماء زينة.
- خطة تدخل متعددة الإجراءات والفئات والمسؤوليات.
- دورة متابعة من خط الأساس إلى إعادة القياس وقرار الاستمرار أو التعديل.
- طلب بيانات إضافية عندما لا تكفي البيانات لتشخيص السبب.
- تقرير رسمي عميق، بطول يحدده المحتوى لا نزوة ضغط كل شيء في صفحة واحدة.

## التطبيق

1. ارفع محتويات حزمة `changed_files_only` إلى جذر المستودع الحالي.
2. لا ترفع ملف ZIP نفسه.
3. لا تعدّل `.github/workflows/deploy.yml`.
4. حدّث كود وظيفة Supabase من الملف المرفق ثم اضغط `Deploy function`.
5. لا توجد أسرار أو SQL أو Storage جديدة.

راجع `APPLY_INSTRUCTIONS.txt` و`docs/TEST_REPORT.md` قبل الاعتماد.
