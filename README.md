# تقارير v0.5.0

## Phase 1-B1: بوابة الذكاء الاصطناعي والتحليل البصري

هذه أول نسخة من «تقارير» يكون فيها الذكاء الاصطناعي جزءًا تشغيليًا من مسار التحليل، لا مجرد كاتب فقرة أخيرة. يبدأ التطبيق بقراءة الملف وفحصه وحساب مؤشراته محليًا، ثم يرسل نسخة محدودة ومراجعة إلى وظيفة خادمية للحصول على تفسير تربوي متخصص واستنتاجات مرتبطة بالأدلة وخطة تحسين قابلة للقياس.

## ما يعمل فعليًا

- قراءة CSV وTSV وTXT الجدولي.
- قراءة XLSX وXLSM واختيار ورقة العمل واكتشاف صف العناوين.
- قراءة DOCX واستخراج الجداول والنصوص محليًا.
- استخراج PDF ذي الطبقة النصية بواسطة PDF.js.
- قراءة الصور وملفات PDF الممسوحة بصريًا عند ربط وظيفة الذكاء الاصطناعي.
- التعرف على نوع النموذج واقتراح نوع جديد عند الحاجة.
- تحليل الدرجات والمستويات والنصوص السردية محليًا.
- تحليل تربوي ذكي متخصص وفق نوع الاستمارة.
- ربط الاستنتاجات بمراجع أدلة من الصفوف أو الأسطر أو المؤشرات.
- التحقق خادميًا من مراجع الأدلة وحذف الإحالات غير الموجودة.
- اقتراح أدوات جودة فقط عند تحقق شروطها.
- إنشاء خطة تحسين تتضمن الأولوية والإجراء والمسؤول والزمن ومؤشر النجاح.
- إخفاء حقول الأسماء والمعرفات المباشرة قبل الإرسال افتراضيًا.
- الاحتفاظ بالتحليل المحلي عند تعذر الذكاء الاصطناعي.
- طباعة النتائج وتصدير JSON.

## المعمارية

```text
GitHub Pages
  ├─ قراءة الملفات محليًا
  ├─ فحص الجودة والحسابات الحتمية
  └─ طلب اختياري إلى Supabase Edge Function
                         └─ OpenAI Responses API
```

لا يوضع مفتاح OpenAI داخل مستودع GitHub أو داخل المتصفح. يوجد المفتاح في أسرار Supabase فقط.

## الملف المناسب للرفع

للتحديث فوق مستودع v0.4.0 استخدم:

`taqareer_phase_1_b1_ai_analysis_gateway_v0_5_0_changed_files_only.zip`

هذه الحزمة لا تحتوي على `.github` أو `.nojekyll` أو النسخ المرئية الاحتياطية، لذلك لا تمس ملف النشر الذي أُنشئ يدويًا.

النسخة `full_backup` للحفظ أو إنشاء مستودع جديد، وتحتوي الملفات المخفية ونسخها المرئية وفق قاعدة المشروع.

## حدود المرحلة

- رمز الوصول الحالي مشترك على مستوى المدرسة، وليس نظام حسابات كاملًا.
- لا توجد بعد حماية دائمة لمعدل الطلبات أو سجل مشاريع سحابي.
- إخفاء البيانات الشخصية يقلل التسرب العرضي، لكنه لا يغني عن مراجعة النصوص الحرة قبل الإرسال.
- الصور وPDF الممسوح يرسلان إلى وظيفة الذكاء الاصطناعي عند تفعيلها؛ بقية القراءة والحسابات محلية ما لم يطلب التحليل الذكي.
- DOC وXLS القديمان وملفات RPT الأصلية غير مدعومة مباشرة.
