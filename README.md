# تقارير v1.1.0

تطبيق لتحليل الاستمارات والبيانات التربوية، يفصل بين **الحساب الموثوق** و**التحليل الذكي**:

- المتصفح يقرأ الملفات ويحسب المؤشرات والرسوم ومراجع الأدلة.
- Gemini هو المحلل التربوي الأساسي.
- بوابات التحقق تمنع الأرقام والمراجع المختلقة والنتائج الناقصة.
- لا تُعرض قوالب محلية محفوظة بوصفها تحليلًا عميقًا.

## جديد Phase 2-C

### محرك PDF إشرافي متعدد الزيارات

- يكتشف تكرار نموذج الزيارة الإشرافية داخل ملف PDF واحد.
- يفصل كل زيارة إلى سجل مستقل يضم المعلم، التاريخ، المادة، الصف، الحصة، عنوان الدرس والتعليقات التابعة لها.
- يستخرج بنود التقويم الثلاثة عشر ويحافظ على المقياس المعكوس: `1 = متميز` و`5 = يحتاج إلى تدخل`.
- يربط جوانب الإجادة والتطوير والدعم والتوصيات بالزيارة نفسها.
- يحسب مؤشرات القسم من كامل الزيارات، ويعرض توزيع المستويات وأداء البنود والزيارات.
- يرصد عدم الاتساق بين التقدير الرقمي والدليل السردي **داخل الزيارة نفسها فقط**.
- يخفي أسماء المعلمين وأرقام الملفات قبل إرسال الحزمة المنظمة إلى Gemini.
- يستخرج المدرسة، الصفوف، العام الدراسي، المحافظة والمواد من PDF عند توفرها.

### المكتسبات المحفوظة

- Gemini محلل أساسي، والحسابات والرسوم المحلية مصدر الحقيقة.
- التفكير المضبوط `low` ومسار الإنقاذ `minimal`.
- الحارس العددي للتدخلات في ملفات الدرجات.
- ترويسات DOCX والتباين السياقي للتقارير التجميعية.
- بوابة الأدلة، والتدخلات المتمايزة، وثلاث مراحل متابعة.

## النشر

1. ارفع ملفات حزمة التغييرات فوق `v1.0.6` مع الاستبدال.
2. استبدل كود وظيفة Supabase بمحتوى `SUPABASE_FUNCTION_GEMINI_V0_14_0.txt`.
3. أعد نشر وظيفة `analyze-educational-form`.
4. لا يوجد SQL جديد ولا سر جديد.
5. اختبر ملف الزيارات نفسه؛ معيار القبول هو فصل 7 زيارات واستخراج 91 تقديرًا.

راجع `README_PHASE_2_C_MULTI_VISIT_PDF.md`.
