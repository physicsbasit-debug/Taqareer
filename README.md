# تقارير v0.9.7

تطبيق للتحليل التربوي التكيفي العميق، يعمل وفق ثلاثة مبادئ: **البساطة، السهولة، والسرعة**.

## جديد v0.9.7

- يبدأ التحسين الذكي تلقائيًا بعد تنفيذ التحليل، دون شاشة انتظار أو زر إعادة يدوي.
- لا تظهر للمستخدم رسائل تقنية عن Gemini أو اسم النموذج داخل صفحة النتائج.
- فشل التحسين الخارجي لا يغيّر الواجهة ولا يعطل التقرير المحلي الكامل.
- الانتقال إلى `gemini-3.5-flash-lite` كنموذج سريع مستقر، مع انتقال تلقائي إلى نموذج بديل عند عدم توفر النموذج المضبوط في الأسرار.
- تبقى الحسابات ومعادلات بوصلة الإتقان والرسوم والتحليل المحلي هي مصدر الحقيقة.
