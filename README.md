# تقارير — Phase 0-C + Phase 1-A Prototype v0.1

هذه أول نسخة مرئية وقابلة للنقر من تطبيق **تقارير**.

## ما يعمل الآن

- رحلة استخدام من أربع خطوات: رفع، فهم، خطة، نتائج.
- اختيار أربعة نماذج مرجعية وتجربة تدفق مختلف لكل نوع.
- عرض تصنيف مقترح ودرجة ثقة وحقول مكتشفة.
- خطة تحليل متكيفة وأدوات جودة مختلفة بحسب النوع.
- نتائج تجريبية واستنتاجات مرتبطة بأدلة.
- مراجعة نوع النموذج يدويًا.
- تصدير ملخص JSON وطباعة صفحة النتائج.
- تصميم عربي RTL متجاوب مع الهاتف والحاسوب.

## ما يزال تجريبيًا

- لا توجد قراءة حقيقية لمحتوى PDF أو Excel في هذه النسخة.
- البيانات والنتائج المعروضة محاكاة لتقييم تجربة الاستخدام والمنطق.
- لا يوجد اتصال حي بنموذج ذكاء اصطناعي أو قاعدة بيانات.
- لا يوجد تسجيل دخول أو صلاحيات في هذه المرحلة.

## قرار القيود المرنة

لا يوقف النظام التحليل إلا عند:

1. تعذر قراءة الملف.
2. غياب الحقول الأساسية التي لا يمكن التحليل من دونها.
3. وجود قيم تجعل الحسابات غير صالحة ولا يمكن تفسيرها بأمان.

أما بقية المشكلات فتظهر كتنبيهات مع استمرار العمل وبيان حدود الثقة.

## التشغيل

افتح `index.html` مباشرة في المتصفح. لا يحتاج إلى تثبيت أو خادم محلي.
