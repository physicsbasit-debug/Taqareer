# تقارير v1.1.2

تطبيق لتحليل الاستمارات والبيانات التربوية، يفصل بين **الحساب الموثوق** و**التحليل الذكي**:

- المتصفح يقرأ الملفات ويحسب المؤشرات والرسوم ومراجع الأدلة.
- Gemini هو المحلل التربوي الأساسي.
- بوابات التحقق تمنع الأرقام والمراجع المختلقة والنتائج الناقصة.
- لا تُعرض قوالب محلية محفوظة بوصفها تحليلًا عميقًا.

## جديد Phase 2-C Fix 2

### تبديل تلقائي عند ازدحام Gemini

- يعيد الطلب المؤقت الفاشل مرتين لكل نموذج باستخدام تراجع أُسّي مع jitter.
- إذا استمر خطأ `503/429/408/5xx` ينتقل تلقائيًا بين:
  1. `gemini-3.5-flash`
  2. `gemini-3.6-flash`
  3. `gemini-3.5-flash-lite`
- يحتفظ مسار الإنقاذ القديم للمخرجات الناقصة، ولا يخلطه مع أعطال السعة المؤقتة.
- لا يعرض رسالة Google الإنجليزية الخام للمستخدم.
- يعيد خطأ عربيًا واضحًا وقابلًا لإعادة المحاولة إذا كانت جميع النماذج مزدحمة.

### مكتسبات Phase 2-C المحفوظة

- فصل الزيارات الإشرافية المتعددة وربط كل جدول بنصه السردي.
- استخراج 13 مؤشرًا بالمقياس المعكوس وربط الرقم بالدليل داخل الزيارة نفسها.
- الرسوم الأربعة الآمنة للطباعة ونطاق الصفوف `8-10`.
- إخفاء أسماء المعلمين وأرقام الملفات قبل إرسال البيانات إلى Gemini.
- الحارس العددي، بوابة الأدلة، التفكير `low`، ومسار الإنقاذ `minimal`.
