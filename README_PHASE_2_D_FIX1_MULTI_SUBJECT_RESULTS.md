# Phase 2-D Fix 1 — Multi-Subject Individual Results

## الهدف

دعم كشوف النتائج الفردية متعددة المواد الناتجة من Crystal Reports أو البنى المشابهة، دون إجبار المستخدم على اختيار عمود درجة واحد من قائمة أعمدة غامضة.

## المعمارية

1. يعيد `xlsx-lite.js` بناء العناوين إلى أزواج واضحة لكل مادة:
   - `<المادة> - الدرجة`
   - `<المادة> - المستوى`
2. يبني `analysis-profile.js` ملفًا دلاليًا بوحدة تحليل `student` ومستوى تجميع `individual`.
3. يوجه `deep-analysis.js` الملف إلى `multi_subject_results`.
4. تبقى الحسابات والرسوم محلية، بينما يبني Gemini التشخيص والاستنتاجات والتدخلات من الأدلة المعتمدة.

## التحليلات الجديدة

- متوسطات المواد وتوزيع أ–هـ لكل مادة.
- نسبة المستويين أ وب، ونسبة د وهـ.
- فصل الانخفاض متعدد المواد عن الانخفاض التخصصي.
- تحديد الأداء المرتفع المتزن.
- فحص اتساق الدرجة الرقمية مع المستوى الحرفي.
- علاقات وصفية بين المواد عند صلاحية البيانات.
- تلخيص حالات القيد دون تفسير سببي.

## الخصوصية

- أسماء الطلبة محجوبة قبل الإرسال.
- الجنسية محجوبة ولا تستخدم في المقارنات أو الاستنتاجات التربوية.
- ملف الاختبار داخل المستودع مصطنع الأسماء ولا يحتوي بيانات تعريفية حقيقية.

## المكتسبات المحفوظة

- التوجيه الدلالي التكيفي.
- محرك الزيارات المتعددة.
- ترويسات DOCX وPDF.
- حارس نطاق العينة والحارس العددي.
- CORS وفحص الاتصال الحي.
- التحكم بالتفكير، التحويل بين النماذج، والإنقاذ عند MAX_TOKENS.
- عدم عرض قوالب محلية بوصفها تحليلًا عميقًا.
