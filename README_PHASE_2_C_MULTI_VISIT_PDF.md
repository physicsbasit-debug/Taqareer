# Phase 2-C — Multi-Visit Supervisory PDF Engine

## المشكلة

ملف الزيارات الإشرافية المتكرر كان يُعامل في الإصدارات السابقة كنص سردي واحد. أدى ذلك إلى:

- إهمال جداول التقويم الرقمية.
- خلط المعلمين والزيارات.
- عدم فهم أن المستوى `1` هو الأفضل و`5` هو الأضعف.
- فقد الربط بين التقدير الرقمي والتعليق السردي داخل الزيارة.
- تصنيف مئات الجمل على أنها توصيات رغم اختلاف أقسامها.

## الحل في v1.1.0

### 1. اكتشاف البنية المتكررة

يبحث القارئ المحلي عن إشارات نموذج الزيارة، وجدول البنود الثلاثة عشر، وبيانات المعلم والزيارة. لا يُفعّل المحرك المتخصص إلا عند وجود أكثر من زيارة وبنية تقويم كافية.

### 2. سجل مستقل لكل زيارة

يبني المحرك سجلًا منظمًا لكل زيارة يحتوي على:

- معرف الزيارة ورقمها وتاريخها.
- اسم المعلم ورقم الملف محليًا.
- المادة والصف والفصل والحصة وعنوان الدرس.
- 13 تقديرًا رقميًا.
- جوانب الإجادة والتطوير والدعم والتوصيات التابعة للزيارة.

### 3. مقياس إشرافي معكوس

المقياس مثبت في العقد:

| المستوى | الوصف |
|---:|---|
| 1 | متميز |
| 2 | جيد |
| 3 | ملائم |
| 4 | غير ملائم |
| 5 | يحتاج إلى تدخل |

لا تُعامل القيم الأعلى بوصفها أداءً أفضل.

### 4. تحليل كمي وسردي مختلط

المحرك المحلي يحسب من كامل البيانات:

- عدد الزيارات والتقديرات المكتملة.
- المتوسط على المقياس المعكوس.
- نسب متميز، متميز أو جيد، وملائم أو أقل.
- توزيع المستويات.
- أداء البنود الثلاثة عشر.
- أداء كل زيارة دون ترتيب شخصي جارح.
- حالات التوتر بين الرقم والدليل السردي داخل الزيارة نفسها.

Gemini يبني التشخيص والاستنتاجات والتدخلات من هذه الأدلة المنظمة، دون إعادة الحساب أو خلط الزيارات.

### 5. الخصوصية

قبل الإرسال إلى Supabase/Gemini:

- يتحول اسم المعلم إلى `المعلم 1`، `المعلم 2`…
- يتحول رقم الملف إلى `[محجوب]`.
- تبقى المادة والصف والتاريخ والدرس والتقديرات والنصوص اللازمة للتحليل.

الأسماء الأصلية تبقى في المتصفح والتقرير المحلي ولا تدخل حمولة الذكاء عند تفعيل الإخفاء الافتراضي.

### 6. سياق الاتساق

- اختلاف ممارسات معلمين أو زيارات مختلفة = تباين سياقي.
- تعارض التقدير الرقمي مع النص داخل الزيارة نفسها = حالة اتساق تحتاج مراجعة.
- لا يصدر النظام حكمًا فرديًا قطعيًا من ملف تجميعي بلا دليل كافٍ.

## التوافق

- لا SQL جديد.
- لا سر جديد.
- لا تغيير في عمليات `ping` و`classify` و`vision_extract`.
- عقد التحليل `6.6.0`.
- Edge `V0.14.0`.
