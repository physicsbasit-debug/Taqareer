# analyze-educational-form — Edge V0.13.0

تدعم وظيفة Edge العمليات التالية:

- `ping`: اختبار الاتصال.
- `classify`: التحقق الدلالي من نوع الاستمارة.
- `vision_extract`: قراءة الصور وملفات PDF المصورة.
- `analyze_primary`: التحليل التربوي الأساسي في v1.0.0.
- `enhance_fast`: متروكة لتوافق العملاء القدامى، ولا تستدعيها واجهة v1.0.0.

## analyze_primary

يستقبل حزمة أدلة لا قوالب تفسيرية محلية، ثم ينشئ:

- الملف التحليلي والملخص التنفيذي.
- قراءات تشخيصية متغيرة العدد.
- حقائق واستنتاجات وفرضيات منفصلة.
- استنتاجات مرتبطة بمراجع أدلة.
- تدخلات قابلة للتنفيذ والقياس.
- خطة متابعة وحدود وطلبات بيانات.

ينظف الخادم مراجع الأدلة ويقبل فقط المراجع الموجودة في `availableEvidenceRefs`. كما يرفض النتيجة إذا لم تتضمن حدًا أدنى من التشخيص والاستنتاجات والتدخلات المرتبطة بالأدلة.

النموذج الأساسي الافتراضي: `gemini-3.6-flash`، مع بدائل محددة في الكود. يمكن تغييره عبر السر `GEMINI_MODEL`.
