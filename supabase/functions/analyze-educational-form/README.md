# analyze-educational-form

وظيفة Supabase Edge التشغيلية الحالية لتطبيق تقارير.

## العقد الحالي — Edge V0.16.0

العمليات العامة:

- `health` و`ping` لفحص الوصول.
- `classify` للتصنيف الدلالي.
- `vision_extract` للاستخراج البصري عند الحاجة.
- `analyze_primary` للتحليل التربوي الأساسي.
- `enhance_fast` محفوظ للتوافق مع العملاء الأقدم فقط؛ الواجهة الحالية تستخدم `analyze_primary`.

### analyze_primary

- عقد التقرير النهائي يبقى `6.6.0`، بينما بروتوكول التنسيق الداخلي للواجهة `6.7.0`.
- المتصفح يرسل طلب Edge واحدًا لكل ضغطة تحليل؛ لا full-request replay تلقائي في مسار التحليل الأساسي.
- Gemini يعيد **نواة قرار واحدة**: ملخصًا، ملف تحليل، 2-3 وحدات تشخيصية، وفحوصًا/تحفظات مرتبطة بالأدلة.
- الخادم يشتق من نواة القرار 2-3 تدخلات وثلاث مراحل متابعة، ويحسب أهداف ملفات الدرجات من `interventionMathContext` بدل طلب الأرقام من Gemini.
- النموذج الأساسي يملك حتى 23 ثانية، ويسمح بـfallback واحد متميز حتى 13 ثانية، داخل مهلة Edge قدرها 38 ثانية. لا `action` منفصل ولا `repair` ولا `segment rescue` في runtime الأساسي.
- في ملفات الدرجات تُرسل المؤشرات والرسوم المحسوبة فقط؛ لا تُرسل `sampleRows` أو مراجع `row:*` إلى نواة القرار.
- `429/RESOURCE_EXHAUSTED` توقف model fan-out فورًا. أخطاء capacity/timeout/network يمكن أن تنتقل مرة واحدة فقط إلى fallback.
- لا تُمرر رسائل Gemini الخام إلى المستخدم، ولا تُعرض نتيجة لا تجتاز عقد الأدلة والتحقق العددي.

### ضبط النماذج مستقبلًا

القيم الافتراضية الحالية محفوظة كما هي. يمكن ضبط أسماء النماذج وقوائم fallback اختياريًا دون تعديل الكود أو التقيد بعائلة `gemini-3` عبر:

- `GEMINI_MODEL` و`GEMINI_GENERAL_FALLBACK_MODELS`
- `GEMINI_FAST_MODEL` و`GEMINI_FAST_FALLBACK_MODELS`
- `GEMINI_CLASSIFIER_MODEL` و`GEMINI_CLASSIFIER_FALLBACK_MODELS`
- `GEMINI_ANALYSIS_MODEL` و`GEMINI_REASONING_FALLBACK_MODELS`

قوائم fallback تقبل قيماً مفصولة بفاصلة أو فاصلة منقوطة أو أسطر. هذه المتغيرات اختيارية ولا تتطلب Secrets جديدة عند إبقاء الإعدادات الافتراضية.

## سياق الزيارات المتعددة

- `recognizedType.id = supervision_multi_visit` يستقبل `data.visits` كسجلات مستقلة.
- المقياس معكوس: `1 متميز` و`5 يحتاج إلى تدخل`.
- لا يرتب المعلمين ترتيبًا شخصيًا ولا يخلط ملاحظات الزيارات.
- عدم الاتساق الرقمي والسردي يُفحص داخل الزيارة نفسها فقط.
- أسماء المعلمين وأرقام الملفات تكون محجوبة افتراضيًا قبل وصولها إلى الوظيفة.
