# Phase 2-D — Adaptive Semantic Analysis Router

## المشكلة

كان التطبيق يمتلك محللات متخصصة، لكنه ما زال يبدأ من قائمة أنواع ثابتة ويعرض إعدادات شبه موحدة. لذلك قرأ كشف توزيع مستويات مجمع وكأنه يحتاج عمود درجة ودرجة كلية وحد إتقان، ثم فشل برسالة أن أعمدة المستويات غير كافية.

## القرار المعماري

النوع لم يعد نقطة البداية الملزمة. نقطة البداية الآن هي `SemanticAnalysisProfile`:

- `shape`
- `unitOfAnalysis`
- `aggregationLevel`
- `measureType`
- `scaleDirection`
- `columnRoles`
- `rowRoles`
- `analysisFamilies`
- `requiresScoreSettings`
- `analyzerId`

القارئ المحلي يحدد البنية والأدوار الحتمية، وGemini يتحقق من المعنى والغرض. إذا اختلفا، تبقى الأدوار البنيوية عالية الثقة محمية، ويضيف Gemini التفسير ومسار النوع الجديد.

## التوجيه

- سجل فردي بدرجة → تحليل درجات وإتقان.
- توزيع مجمع لمستويات → تحليل توزيع ومقارنة مجموعات، بلا إعدادات درجات.
- مؤشرات متعددة → تحليل فجوات وترتيب ومقارنة.
- نص سردي → تحليل أدلة واتساق وتوصيات.
- نوع جديد → ملف دلالي تكيفي ومحلل عام، دون إجباره على نوع معروف.

## حارس صف الإجمالي

صف الإجمالي لا يدخل ضمن سجلات الشعب. يستخدم فقط للتحقق من:

- إجمالي الطلبة.
- جملة النجاح.
- نسبة النجاح.

وهذا يمنع مضاعفة الأعداد.
