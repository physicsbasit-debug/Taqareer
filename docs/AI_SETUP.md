# إعداد Gemini وSupabase لتقارير v0.9.3

## الأسرار المطلوبة

في `Edge Functions → Secrets`:

- `GEMINI_API_KEY`
- `GEMINI_MODEL`
- `TAQAREER_ACCESS_CODE`
- `TAQAREER_ALLOWED_ORIGINS`

لا يوضع مفتاح Gemini داخل المتصفح.

## نشر وظيفة التحليل

1. افتح `Edge Functions`.
2. افتح `analyze-educational-form`.
3. افتح `Code → Edit function`.
4. احذف الكود القديم كاملًا.
5. الصق محتوى `SUPABASE_FUNCTION_GEMINI_V0_8_1.txt`.
6. اضغط `Deploy function`.

لا يلزم SQL أو جدول أو سر جديد.

## ربط التطبيق

داخل إعداد الذكاء الاصطناعي أدخل:

- رابط الوظيفة الحقيقي.
- Supabase publishable key.
- قيمة `TAQAREER_ACCESS_CODE`.

ثم اضغط `حفظ واختبار`.

## العملية الحالية

تستخدم الواجهة عملية:

`enrich_segment`

وترسل أحد الأجزاء:

- `diagnostic`
- `findings`
- `interventions`
- `governance`

## اختبار القبول

بعد النشر:

1. حلل ملفًا معروفًا.
2. يجب أن تظهر النتائج المحلية فورًا.
3. يظهر تقدم الأجزاء من 0 إلى 4.
4. عند فشل جزء مؤقتًا، تظهر الاستعادة الآلية 1/2 ثم 2/2 دون ضغط المستخدم.
5. لا يظهر زر الإعادة اليدوية إلا إذا استنفدت الجولتان أو كان الخطأ غير قابل للإعادة.
6. عند النجاح الكامل، تظهر رسالة `اكتملت المصالحة التحليلية المقسّمة` مع عدد الأجزاء المستعادة تلقائيًا.
