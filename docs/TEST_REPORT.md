# تقرير فحص تقارير v0.7.1

## نطاق المرحلة
إعادة بناء إخراج التقرير الرسمي من تخطيط تدفقي غير متزن إلى صفحات A4 تحريرية مستقلة ومتوازنة.

## الفحوص الناجحة
- `node --check` لملفات JavaScript المعدلة.
- اختبارات محرك التحليل لـ 12 عائلة: PASS.
- قراءة ملف Excel الوزاري الحقيقي: 268 سجلًا و5 حقول منطقية.
- توليد تقرير الدرجات: 6 صفحات A4.
- توليد التقرير الإشرافي السردي: 8 صفحات A4.
- فحص كل صفحة في Chromium: لا تجاوز رأسي أو أفقي (`scrollHeight == clientHeight`).
- طباعة PDF بهوامش صفرية مع `prefer_css_page_size`: لا صفحات بيضاء إضافية.
- رندر PDF إلى PNG وفحص بصري للصفحات.
- معالجة البطاقة الفردية الأخيرة في شبكة الاستنتاجات بجعلها بعرض الصف كاملًا.
- تحويل خطة التدخل إلى بطاقات تنفيذية بدل جدول كثيف.
- عرض الرسوم الشريطية بالعدد والنسبة.
- الحفاظ على `.github/workflows/deploy.yml` في النسخة الكاملة، وعدم تضمينه في changed files only.

## ملاحظات التحقق البصري
- تقرير الدرجات: توزيع متوازن للملخص، الرسوم، القراءات، الاستنتاجات، التدخلات، والمتابعة.
- التقرير السردي: الرسوم الواسعة والصغيرة تجمع في صفحات متوازنة، والاستنتاجات السبعة موزعة 4 + 3 دون بطاقة يتيمة ضيقة.
- لم يتم تغيير عقد Gemini أو Supabase في هذه المرحلة.
