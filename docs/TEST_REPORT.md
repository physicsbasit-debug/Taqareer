## اختبار القبول الحي

بعد رفع GitHub ونشر `SUPABASE_FUNCTION_GEMINI_V0_8_1.txt`:

1. نفذ تحليلًا جديدًا.
2. عند تعثر جزء مؤقتًا يجب أن تبدأ الاستعادة تلقائيًا.
3. لا تضغط أي زر أثناء جولتي الاستعادة.
4. يجب أن يظل العداد 3/4 ثم ينتقل إلى 4/4 عند النجاح.
5. يظهر زر الإعادة فقط إذا استنفدت الجولتان أو كان الخطأ غير قابل للإعادة.
