# تقرير فحص تقارير v0.8.2

## الفحوص الناجحة

- فحص JavaScript لكل ملفات التشغيل.
- فحص TypeScript لوظيفة Supabase مع تعريف Deno اختباري.
- جميع اختبارات بوصلة الإتقان.
- اختبار ملف الوزارة الحقيقي `aaaa.xlsx` ونتائج 268 سجلًا.
- اختبارات 11 عائلة تحليلية والمحلل التكيفي.
- اختبار التقرير الرسمي وعقد اكتمال الرسوم.
- اختبار بصمة الذاكرة المؤقتة والتخزين والحذف.
- اختبار عقد المسار السريع: العينة الصغيرة، الظهور المرحلي، زر إعادة الذكاء، النموذج الخفيف، وميزانية التفكير.
- اختبار حجم الحمولة: انخفض نموذج الاختبار من 41,828 إلى 16,896 حرفًا، أي إلى 40.4% من الحجم السابق، مع بقاء حساب 268 سجلًا محليًا كاملًا.
- اختبار overlay فوق v0.8.1 مع الحفاظ على `.github/workflows/deploy.yml`.
- تشغيل الموقع عبر خادم HTTP وفحص تحميل الملفات الأساسية.

## قيد بيئة الاختبار

تعذر تشغيل اختبار Chromium الآلي داخل بيئة التجهيز بسبب سياسة `ERR_BLOCKED_BY_ADMINISTRATOR` التي تمنع تنقل المتصفح حتى إلى عناوين محلية أو معترضة. أُبقي سيناريو الاختبار اليدوي في `tests/browser-fast-pipeline.manual.py`، ولم يُدّع نجاحه آليًا.

## اختبار القبول الحي المطلوب

بعد نشر وظيفة Supabase:

1. حلل `aaaa.xlsx` مع الذكاء الاصطناعي.
2. تأكد أن المؤشرات والرسوم تظهر فورًا.
3. سجل زمن Gemini الظاهر.
4. أعد التحليل بالإعدادات نفسها.
5. تأكد من الاسترجاع من الذاكرة المؤقتة وعدم الانتظار الطويل.
