# عقد الذكاء الاصطناعي v0.9.7

## المسؤوليات

- المحرك المحلي المتخصص يملك الحسابات والرسوم وأدوات الجودة والبنية الأساسية للتقرير.
- التحسين الخارجي يبدأ تلقائيًا بعد ظهور النتائج، ويعمق التفسير داخل العناصر الموجودة فقط.
- لا يغير التحسين الخارجي الأرقام أو الفئات أو معادلات بوصلة الإتقان أو عدد التدخلات والمتابعة.

## تجربة المستخدم

- لا تظهر مرحلة مستقلة باسم Gemini.
- لا توجد رسالة انتظار أو زر إعادة يدوي في صفحة النتائج.
- نجاح التحسين يدمج بصمت.
- الفشل يبقي التقرير المحلي كاملًا ويُسجل فنيًا فقط.

## التشغيل الخادمي

- النموذج الافتراضي السريع: `gemini-3.5-flash-lite`.
- عند عدم توفر النموذج المضبوط في السر تنتقل الوظيفة تلقائيًا إلى بديل مستقر.
