# عقد الذكاء الاصطناعي v0.9.5

## المسؤوليات

- المحرك المحلي: الحسابات، الأدلة، الرسوم، اختيار أدوات الجودة وشروطها.
- Gemini: القراءة التربوية العميقة والتحسينات السياقية.
- المصالحة: منع تغيير الحسابات والتكرار والمعرفات أو الأدلة غير الصالحة.

## البروتوكولات

- عقد المصالحة المحلي: `3.0.0`.
- بروتوكول المهام: `4.2.0`.
- محرك الجودة الدقيقة: `1.0.0`.

## المهام

| المحور | المهام |
|---|---|
| التشخيص | `diagnostic.full` وقد يُفكك إلى دفعات |
| الاستنتاجات | `findings.full` وقد يُفكك إلى دفعات |
| التدخلات | `interventions.full` وقد يُفكك إلى دفعات |
| الجودة | `quality.<tool-id>`، مهمة واحدة لكل أداة |
| المتابعة | `governance.monitoring` |

فشل محتوى مهمة جودة اختيارية بعد المحاولة المركزة لا يعطل التقرير؛ يعتمد تفسير المحرك المحلي ويُسجل ذلك في حالة التشغيل.
