# عمارة المصالحة التحليلية في تقارير v0.9.4

## الطبقات

```text
استقبال الملف وتطبيعه
→ محلل النوع المتخصص
→ عقد حتمي بالأدلة والمعرفات
→ منسق مهام Gemini المعزولة
→ تحقق خادمي لكل مهمة
→ مصالحة حقلية مرحلية
→ تقرير رسمي واحد
```

## الحتمية

تملك الطبقة المحلية وحدها:

- الحسابات والإحصاءات.
- معادلات بوصلة الإتقان.
- الفئات والأعداد والرسوم.
- شروط تطبيق أدوات الجودة.
- أعداد الاستنتاجات والتدخلات والمتابعة المقفلة.

## التحليل العميق

يعمل Gemini ضمن مهام صغيرة محددة الهدف. الحوكمة مفصولة دائمًا، والمهام الكبيرة قابلة للتفكيك حسب المعرفات عند فشل المحتوى.

## المصالحة المرحلية

عند وصول أي مهمة ناجحة:

1. يتحقق الخادم من معرفاتها وحقولها وأدلتها.
2. تطبق على نسخة من العقد المحلي.
3. تتحقق الأعداد المقفلة.
4. يعاد عرض النتيجة فورًا.

فشل مهمة أخرى لا يتراجع عن التحسينات المقبولة سابقًا.

## منع التكرار

- رقعة واحدة لكل `targetType + targetId + field`.
- لا إنشاء تدخلات أو مراحل متابعة جديدة.
- لا إضافة استنتاجات موازية في تحليل الدرجات.
- تبقى النتيجة تقريرًا واحدًا مصالَحًا.
