# عمارة المصالحة التحليلية في تقارير v0.9.1

## المبدأ

يوجد نموذج تحليل رسمي واحد فقط. يبنيه المحرك المتخصص، ثم يثريه Gemini دون إنشاء تقرير أو خطة موازية.

```text
ملف خام
→ تطبيع وفحص جودة
→ محلل متخصص بالنوع
→ عقد رسمي بمعرفات ثابتة
→ Gemini Deep Analysis Delta
→ تحقق خادمي
→ مصالحة حقلية
→ واجهة وتقرير من النموذج نفسه
```

## طبقتا Gemini

1. `deepAnalysisUnits`: وحدات تفسير تربوي كاملة لكل محور تشخيصي.
2. `patches`: تحسينات تنفيذية محددة على حقل مسموح داخل عنصر قائم.

لا يسمح البروتوكول بإضافة تدخلات أو مراحل متابعة موازية في تحليل الدرجات.

## الحقول المغلقة

- الأعداد والنسب.
- درجات الحدود.
- فئات الإتقان.
- المعرفات.
- عدد التدخلات والمتابعة المقفل.
- صلاحية أداة الجودة الحتمية.

## الأمان عند الفشل

- `MAX_TOKENS` لا يمر إلى `JSON.parse` بوصفه ردًا صالحًا.
- توجد محاولة مختصرة واحدة فقط.
- النتيجة الفاشلة لا تخزن.
- التحليل المحلي والرسوم لا يضيعان.
