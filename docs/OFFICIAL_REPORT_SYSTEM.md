# نظام التقرير الرسمي العميق v0.7.0

التقرير الرسمي لم يعد بطاقة ملخص قصيرة، ولا نسخة مطبوعة من لوحة التحكم. إنه مستند ديناميكي يتوسع بحسب نوع الاستمارة وثراء البيانات.

## الأقسام

1. بيانات التقرير ونوع الاستمارة.
2. الملخص التنفيذي ومستوى كفاية البيانات.
3. المؤشرات الرئيسة الخاصة بالنوع.
4. الملف المنهجي وأبعاد القرار.
5. الرسوم والتحليل البصري.
6. القراءة التفسيرية المتخصصة.
7. الاستنتاجات التشخيصية مع الأدلة والأثر والحدود.
8. أدوات الجودة المطبقة ونتائجها.
9. خطة التحسين والتدخل متعددة الإجراءات.
10. خطة المتابعة وإعادة القياس.
11. حدود التحليل والبيانات المطلوبة.
12. الاعتماد والمتابعة.

## إدارة الصفحات

- لا يفرض عددًا ثابتًا للصفحات.
- لا يضغط التحليل العميق في صفحة واحدة.
- لا يترك صفحات فارغة أو مساحات مترفة.
- يمنع انقسام الرسوم والبطاقات والصفوف المهمة.
- يسمح بفاصل صفحة قبل الأقسام الكبرى فقط.

## الرسوم المدعومة

- أعمدة وتوزيعات.
- خطوط واتجاهات.
- Box plot.
- رادار.
- خرائط حرارية.
- جداول مقارنة.
- باريتو.

يختار المحلل المتخصص الرسوم، وليس قالب التقرير.
