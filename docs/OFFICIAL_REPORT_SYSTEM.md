# نظام التقرير الرسمي في تقارير v1.2.31

## هندسة الورق

- المقاس المرجعي الوحيد للتقرير الرسمي هو **A4 عمودي 210 × 297 مم**.
- لا يستخدم التقرير غلاف Letter ولا تحجيمًا ثابتًا لتصغير A4 داخل ورقة أقصر.
- تضبط قاعدة الطباعة `@page` على A4 مع أبعاد صريحة للصفحة في وضع الطباعة.
- عند استخدام برنامج تشغيل طابعة مستقل مثل Microsoft Print to PDF قد يفرض برنامج التشغيل مقاسه الخاص؛ لذلك تعرض واجهة التقرير تنبيهًا واضحًا لاختيار A4 من خصائص الطابعة.

## تعبئة الصفحات

- الصفحات التحليلية الوسطية قابلة للتعبئة الذكية على مستوى جميع أنواع التقارير.
- بعد اكتمال الرسم في المتصفح، يقيس المحرك الارتفاع الحقيقي للمحتوى داخل صفحة A4.
- يحاول دمج الصفحات التحليلية المتجاورة فقط عندما يتسع المحتوى فعليًا قبل التذييل.
- إذا أدى الدمج إلى تجاوز ارتفاع A4، يتراجع عنه تلقائيًا ولا يعتمد التخمين أو عدد البطاقات وحده.
- الملخص التنفيذي وصفحات جداول الترتيب تبقى مستقلة لأنها ذات عقود طباعة خاصة.
- عند نجاح الدمج يعاد ترقيم الصفحات تلقائيًا وتظهر أسماء الأقسام المدمجة في ترويسة الصفحة.

## حراس السلامة

- يفحص التقرير بعد التعبئة أي تجاوز لمحتوى الصفحة قبل التذييل.
- تبقى حراس قص الرسوم، جداول الترتيب، وبطاقات خطة التدخل مفعلة.
- لا تستخدم زيادة ارتفاع البطاقات الفارغة كوسيلة لملء الصفحة؛ الهدف هو تقليل الهدر الحقيقي لا تصنيع مساحة مزيفة.
