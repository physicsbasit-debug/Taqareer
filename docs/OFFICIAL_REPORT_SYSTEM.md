# نظام التقرير الرسمي في تقارير — Print Report V2

## القرار المعماري

- Renderer الإنتاجي الافتراضي هو **Print Report V2** في `assets/print-report-v2.js`.
- `assets/report-system.js` يبقى مصدر تطبيع بيانات التقرير ومحرّكًا تقليديًا احتياطيًا؛ لا يُحذف قبل اكتمال قبول V2 على أنواع الملفات المختلفة.
- V2 لا يحسب مؤشرات ولا يعيد ترتيب أسماء أو أوائل؛ يستهلك `TaqareerReports.buildReportData()` مباشرة.

## فلسفة الصفحة

- المقاس المرجعي الوحيد هو **A4 عمودي 210 × 297 مم**.
- الصفحة هي الوحدة التصميمية الأساسية، لا البطاقة.
- لكل صفحة وظيفة قرار واضحة: ملخص، مؤشرات، قراءة تفسيرية، خريطة قرار، خطة تحسين، متابعة/حوكمة، أو جداول أوائل.
- لا يوجد flow paginator يعيد تشكيل التقرير بعد تحميله؛ توزيع المحتوى يحدد قبل إنشاء الصفحات وفق عقود كثافة بسيطة ومحافظة.
- لا يُصغّر الخط لحل المساحة، ولا يُحذف المحتوى لتقليل عدد الصفحات.

## الهوية البصرية

- كحلي عميق `#102E4A` للرسمية والثقة.
- تركواز `#0F7C77` للمؤشرات التربوية والإشارات الإيجابية.
- ذهبي `#C59A45` للدليل والتنبيه والأولوية باستخدام محدود.
- العناوين تفضّل `Noto Kufi Arabic` والنصوص `Noto Sans Arabic` مع fallbacks آمنة.

## هيكل التقرير الكامل

1. الملخص التنفيذي + بيانات المصدر + 6 مؤشرات + رسمان أساسيان.
2. لوحة المؤشرات والتحليل الإحصائي والرسوم المتخصصة.
3. القراءة التفسيرية مع رتبة الاستدلال.
4. خريطة القرار والاستنتاجات في جدول مركز.
5. خطة التحسين والتدخل.
6. المتابعة والحوكمة والاعتماد.
7. الأوائل العامون ثم 2–3 جداول مواد في الصفحة حسب عدد الصفوف.

## مسار التقرير في الواجهة

- تعرض الواجهة للمستخدم **تقريرًا كاملًا واحدًا فقط** عبر زر «فتح التقرير الكامل».
- لا يوجد زر مستقل للتقرير التنفيذي؛ الصفحة الافتتاحية في التقرير الكامل تظهر للمستخدم باسم «الخلاصة العامة»، وليست تقريرًا موازيًا.
- يبقى وضع `executive` داخل طبقة Renderer مؤقتًا للتوافق الاختباري والرجوع الآمن، لكنه غير موصول بمسار المستخدم.

## حراس السلامة

- حارس overflow لكل صفحة قبل التذييل.
- حارس أعداد للتشخيصات والاستنتاجات والتدخلات ومراحل المتابعة وجداول الترتيب.
- الاسم الكامل وترتيب القبيلة يأتيان من مصدر البيانات الموثوق ولا يعاد تركيبهما داخل Renderer.
- الحقيقة/الاستنتاج/الفرضية تُعرض من `claimType` الحالي ولا يعاد تفسيرها في طبقة العرض.

## fallback

- `openOfficialReport()` يفضّل `TaqareerPrintReportV2`.
- إذا فشل V2 في البناء، يفتح `TaqareerReports` القديم تلقائيًا.
- هذا fallback تشغيلي فقط، وليس مسارًا موازيًا لإعادة الحساب.
