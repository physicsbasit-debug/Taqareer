# الإصدار النهائي المستقر — تقارير v1.4.6

تاريخ التثبيت: 2026-08-10

تم اعتماد `v1.4.6` كنقطة الاستقرار النهائية للدورة الحالية بعد إغلاق مسارات الإدخال والتحليل والتقرير والحراسة التربوية واختبار ملف Excel حي متعدد المواد.

## الحالة المعتمدة

- التطبيق: `v1.4.6`
- Supabase Edge: `V0.16.5`
- SQL جديد: لا
- Secrets جديدة: لا
- إعادة فهرسة: لا
- منطق ترتيب الأوائل: مثبت وفق `docs/RANKING_POLICY.md`

## أهم ما يغطيه الإصدار

- استقبال Excel وCSV وWord وPDF النصي والصور وPDF الممسوح.
- التعرف التكيفي على نوع المصدر وتوجيهه إلى المحلل المتخصص.
- تحليل الدرجات والمستويات والمواد المتعددة والتقارير الإشرافية والزيارات المتعددة.
- تقرير كامل واحد للطباعة، مع الرسوم والاستنتاجات وخطة التحسين والمتابعة.
- حراس الاستدلال التربوي: حجم العينة، Missing ≠ Zero، قابلية المقارنة، المستهدفات الرقمية، وفصل الحضور السردي عن جودة الأداء.
- ترتيب أوائل المواد والمدرسة مع حماية الأسماء محليًا.
- إصلاح End-to-End لكشوف Excel متعددة المواد الصغيرة دون المساس بسلوك الملفات الواقعية الكبيرة.

## قاعدة الصيانة بعد هذا الإصدار

يعد هذا الإصدار baseline مستقرة. أي تطوير لاحق يبدأ من `v1.4.6` ويجب ألا يعيد فتح مسارات مستقرة دون خطأ قابل لإعادة الإنتاج أو مطلب وظيفي واضح.
