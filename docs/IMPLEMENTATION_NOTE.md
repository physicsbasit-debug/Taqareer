# مذكرة التنفيذ — النسخة الأولى من تقارير

## القرار

دمجنا Phase 0-C الخاصة بتجربة المستخدم مع بداية Phase 1-A في نموذج أولي واحد. الهدف هو إظهار تقدم مرئي مبكرًا بدل إنتاج وثائق إضافية لا يمكن اختبارها بصريًا.

## مبادئ الواجهة

- أربع خطوات فقط.
- لا تظهر الإعدادات التقنية للمستخدم.
- التصنيف قابل للمراجعة دون تعطيل المسار.
- الأنواع الجديدة لا ترفض، بل تُحلل بخطة مؤقتة ثم تحفظ لاحقًا.
- القيود الصارمة محصورة في الأخطاء التي تفسد التحليل فعليًا.

## المرحلة التالية

1. تحويل النموذج إلى مشروع React + TypeScript منظم.
2. بناء قارئ Excel/CSV فعلي محليًا.
3. إضافة طبقة استخراج PDF والصور.
4. ربط سجل أنواع الاستمارات الحالي.
5. إضافة موفر ذكاء اصطناعي قابل للاستبدال دون ربط التطبيق بمزود واحد.
6. نشر رابط معاينة دائم.
