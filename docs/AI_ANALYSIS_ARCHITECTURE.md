# عمارة الذكاء الاصطناعي للتحليل التربوي

## 1. المبدأ

الذكاء الاصطناعي مكوّن مركزي في المنصة، وليس طبقة لصياغة التقرير فقط. ومع ذلك لا ينفذ العمليات التي تتطلب دقة حسابية أو قواعد صلاحيات أو تحققًا حتميًا.

## 2. خط المعالجة

```text
رفع الملف
→ استخراج النص والجداول والصور
→ تقييم جودة الاستخراج
→ فهم الوثيقة وتحديد الهدف
→ تصنيف النوع أو اقتراح نوع جديد
→ بناء خطة تحليل متكيفة
→ تنفيذ التحليلات الحتمية
→ تحليل النصوص والأدلة بالذكاء الاصطناعي
→ إنشاء استنتاجات مرتبطة بالأدلة
→ توليد توصيات وخطة تحسين
→ مراجعة بشرية
→ تقرير معتمد
```

## 3. وكلاء الذكاء الاصطناعي المنطقيون

### 3.1 وكيل فهم الوثيقة

- يحدد العنوان والجهة والفترة والصف والمادة.
- يميز بين رأس التقرير والجدول والحواشي.
- يتعرف على الأقسام السردية.
- يقترح وحدة التحليل.

### 3.2 وكيل تصنيف النوع

- يستخدم إشارات العنوان والحقول والقيم والسياق.
- ينتج قائمة احتمالات مع درجة الثقة وأسباب الاختيار.
- لا يخفي عدم اليقين.

### 3.3 وكيل خطة التحليل

ينشئ خطة تتضمن:

- الأسئلة التحليلية.
- المؤشرات المطلوبة.
- التحليلات الحتمية.
- التحليلات النوعية.
- أدوات الجودة المناسبة.
- المخاطر والقيود.
- شكل التقرير.

### 3.4 وكيل تحليل الأدلة السردية

- يفصل الحكم عن الدليل والأثر.
- يصنف الممارسة حسب المجال.
- يكتشف العمومية والمبالغة والتكرار والتعارض.
- يقيم قوة الدليل.

### 3.5 وكيل الاستدلال التربوي

- يفسر النتائج ضمن الغرض التربوي.
- يقترح استنتاجات لا تتجاوز الأدلة.
- يميز بين حقيقة، نمط، فرضية، وتكهن.

### 3.6 وكيل التوصيات وخطة التحسين

يبني كل توصية من:

- نتيجة أو فجوة محددة.
- إجراء قابل للتنفيذ.
- فئة مستهدفة.
- مسؤول وزمن.
- مؤشر نجاح.
- أداة متابعة.

### 3.7 المساعد الحواري

يجيب من بيانات المشروع وأدلته، مثل:

- لماذا صُنّفت هذه المهارة كأولوية؟
- ما الأدلة على الاستنتاج؟
- ما الحالات التي تحتاج مراجعة؟
- لخص النتائج للإدارة.
- أنشئ خطة علاجية لأربعة أسابيع.

## 4. المهام الحتمية

تنفذ برمجيًا دون الاعتماد على نموذج لغوي:

- الحسابات والإحصاءات.
- النسب والتوزيعات.
- نطاقات القيم.
- كشف التكرارات.
- مطابقة السجلات.
- تطبيق معيار الإتقان.
- تحديد القيم المفقودة.
- إدارة الصلاحيات والتخزين والتصدير.

## 5. عقد مخرجات الذكاء الاصطناعي

كل استجابة داخلية يجب أن تكون بنية قابلة للتحقق، وليست نصًا حرًا فقط، وتحتوي على:

- المهمة.
- المدخلات المرجعية.
- النتيجة.
- الأدلة.
- درجة الثقة.
- القيود.
- هل تحتاج مراجعة بشرية؟
- نسخة الموجه والنموذج.

## 6. منع الهلوسة

- لا يقبل استنتاج بلا مرجع دليل.
- لا يسمح بإضافة أسماء أو درجات غير موجودة.
- لا يملأ القيم المفقودة صامتًا.
- لا يحول الارتباط إلى سببية.
- لا يقرر سببًا جذريًا دون بيانات تحقق.
- يعيد عبارة `غير مدعوم بالبيانات الحالية` عندما لا تكفي الأدلة.

## 7. الخصوصية

- إزالة الأسماء من طلبات الذكاء الاصطناعي متى لم تكن ضرورية.
- استخدام معرفات مؤقتة للطلبة والمعلمين.
- فصل بيانات المؤسسة عن أي بيانات تدريب.
- تسجيل أي إرسال خارجي للبيانات.
- توفير وضع معالجة محلية أو مزود مؤسسي لاحقًا.

## 8. الإصدار والتتبع

يجب حفظ:

- نسخة تعريف النوع.
- نسخة خطة التحليل.
- نسخة القواعد التربوية.
- نسخة الموجه.
- اسم النموذج وإعداده.
- تاريخ التوليد.
- تعديلات المستخدم.

وبذلك يمكن إعادة إنتاج التقرير ومعرفة سبب اختلاف النتائج بين نسختين.
