# تقارير v0.7.1 - إعادة بناء الإخراج التحريري

تعيد هذه المرحلة بناء التقرير الرسمي من جذوره بصيغة صفحات A4 مستقلة ومتوازنة.

## ما تغير
- فصل التقرير إلى صفحات وظيفية: الملخص، التحليل المتقدم، القراءة التفسيرية، الاستنتاجات، أدوات الجودة وخطة التدخل، المتابعة والحوكمة.
- منع البطاقة اليتيمة وتوزيع البطاقات بمجموعات متوازنة.
- رفع الحد الأدنى لحجم الخط وتحسين المسافات السطرية.
- تحويل خطة التحسين من جدول كثيف إلى بطاقات تنفيذية.
- عرض رسوم فعلية مع العدد والنسبة بدل القوائم النصية.
- استخدام مقاس A4 بصفحات ثابتة و@page بلا هوامش إضافية لمنع الصفحات البيضاء.
- التقرير ديناميكي: يزيد عدد الصفحات عندما يزيد المحتوى بدل ضغطه أو ترك مساحات ميتة.

لا يحتاج الإصدار إلى تعديل Supabase أو Gemini.
