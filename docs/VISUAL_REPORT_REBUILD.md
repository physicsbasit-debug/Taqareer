# تقارير v0.7.2 - محرك الطباعة المتوافق مع A4 وLetter

يعالج هذا الإصدار الجذر الحقيقي للصفحات البيضاء المتبادلة عند استخدام Microsoft Print to PDF أو طابعة مضبوطة على Letter.

## السبب الجذري
كان التقرير يبني كل صفحة بارتفاع A4 كامل 297mm. وعندما يختار نظام الطباعة ورق Letter بارتفاع أقصر، يتجاوز كل قسم الصفحة بنحو 18mm، فينشئ النظام صفحة إضافية تحتوي بقايا التذييل أو فراغًا أبيض.

## الحل المعماري
- إضافة غلاف طباعة مستقل `report-sheet` بارتفاع آمن 276mm يناسب A4 وLetter.
- إبقاء التصميم الداخلي على لوحة A4 أصلية ثم تحجيمه كاملًا بنسبة ثابتة 92.93% داخل الغلاف، من دون قص المحتوى أو تغيير توزيع الأقسام.
- نقل فواصل الصفحات إلى الغلاف الخارجي بدل عنصر المحتوى.
- الحفاظ على @page A4 مع ضمان عدم تضاعف الصفحات إذا تجاهل برنامج الطباعة الإعداد واستخدم Letter.
- إضافة print-color-adjust للحفاظ على الهوية والألوان.
- إبقاء عرض الجوال غير محجّم ومفتوح الارتفاع.

## نتيجة الاختبار
- تقرير الدرجات: 6 صفحات محتوى فعلية على A4 و6 صفحات على Letter، دون صفحات بيضاء.
- التقرير السردي: 8 صفحات محتوى فعلية على A4 و8 صفحات على Letter، دون صفحات بيضاء.
- لا قص في الترويسة أو التذييل أو البطاقات.

لا يحتاج الإصدار إلى تعديل Supabase أو Gemini.
