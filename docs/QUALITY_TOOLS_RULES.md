# قواعد أدوات الجودة

## 1. المبدأ

لا تعرض أداة جودة لأنها جميلة أو مألوفة، بل لأنها تجيب عن سؤال تحليلي وتتوفر شروط استخدامها.

| الأداة | شروط الاستخدام | المخرج | حالات المنع |
|---|---|---|---|
| تحليل الفجوة | قيمة حالية + مستوى مستهدف مؤكد | حجم الفجوة وترتيبها | غياب الهدف أو اختلاف المقاييس |
| باريتو | فئات مشكلات أو أخطاء + تكرارات كافية | أكثر الأسباب أو الأخطاء إسهامًا | بيانات فردية غير متكررة |
| الرادار | مجالات متعددة على مقياس موحد | ملف بصري للمجالات | اختلاف المقاييس أو كثرة المجالات |
| خريطة الحرارة | مصفوفة صفوف × مؤشرات | أنماط القوة والضعف | بيانات قليلة أو غير قابلة للمقارنة |
| الاتجاه الزمني | ثلاث نقاط زمنية مفضلة أو أكثر | تحسن أو تراجع | فترات غير مرتبة أو مقاييس مختلفة |
| مقارنة قبل/بعد | نفس المقياس وفئة قابلة للمطابقة | أثر أولي | تغير العينة أو الأداة دون ضبط |
| مصفوفة الأولوية | عدة تدخلات مع أثر وجهد | ترتيب التنفيذ | غياب معايير الأثر والجهد |
| PDCA | خطة تحسين لها دورة متابعة | مسار تنفيذ ومراجعة | توصية منفردة بلا متابعة |
| عظمة السمكة | مشكلة محددة وفريق بشري يراجع الأسباب | فرضيات أسباب | تقديم الأسباب كحقائق آلية |
| الأسباب الخمسة | مشكلة محددة وسلسلة تحقق | تعميق الاستقصاء | استخدامها آليًا بلا أدلة |
| Rubric | أداء أو منتج بمعايير واضحة | مستوى وفق أبعاد | غياب معايير وصفية معتمدة |
| الاتساق الداخلي | بنود تقيس بناءً واحدًا وعينة مناسبة | مؤشر اتساق | استبانة متعددة الأبعاد بلا فصل |

## 2. اختيار الأداة

ينتج محرك الاختيار لكل أداة:

- سبب الاختيار.
- البيانات المستخدمة.
- الشروط المتحققة.
- التحذيرات.
- القيمة التي ستضيفها.

## 3. الأولوية التربوية

يمكن ترتيب الفجوات وفق صيغة قابلة للضبط:

```text
درجة الأولوية = حجم الفجوة × الانتشار × الأثر التربوي × موثوقية الدليل
```

لا تعتمد الأوزان النهائية قبل اختبارها مع المستخدمين، ويجب عرض سبب ترتيب كل أولوية.

## 4. أدوات لا تنفذ آليًا بالكامل

- عظمة السمكة.
- الأسباب الخمسة.
- SWOT.
- تحليل السبب الجذري.

يولد الذكاء الاصطناعي مسودة فرضيات، ثم يعتمدها فريق بشري.
