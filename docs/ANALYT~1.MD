# عمارة المصالحة التحليلية في تقارير v0.9.0

## المشكلة التي ألغتها هذه المرحلة

في v0.8.2 كان المحرك المحلي يبني استنتاجاته وخطة التدخل والمتابعة، ثم يعيد Gemini استنتاجات وخطة ومتابعة كاملة أخرى. كانت الواجهة والتقرير تجمع القائمتين، فنتجت تدخلات ومراحل متابعة مكررة رغم اختلاف الصياغة.

الحل ليس حذف العناصر المتكررة بعد توليدها، بل تغيير عقد العمل نفسه.

## المبدأ الحاكم

المحرك الحتمي المتخصص هو صاحب العقد الرسمي الوحيد، لأنه يملك:

- الحسابات والمعادلات.
- فئات التدخل وأعدادها.
- الأدلة الرقمية.
- الرسوم وأدوات الجودة المشروطة.
- الحدود التي تفرضها طبيعة البيانات.

Gemini لا ينشئ تقريرًا ثانيًا. يعيد تحسينات `Delta` تستهدف عناصر موجودة عبر معرفات ثابتة.

## خط التنفيذ

```text
الملف
→ التطبيع وفحص الجودة
→ المحلل المتخصص
→ Canonical Analysis Contract
→ Compact Dossier + Reconciliation Contract
→ Supabase operation: enrich
→ Gemini Enrichment Delta
→ Server validation
→ Client reconciliation
→ Single Effective Analysis
→ UI + JSON + Official Report
```

## العناصر المقفلة

في عائلة تحليل الدرجات يثبت العقد:

| العنصر | العدد |
|---|---:|
| القراءات التشخيصية | 4 |
| الاستنتاجات | 5 |
| التدخلات | 4 |
| مراحل المتابعة | 4 |

لا يسمح بإضافات موازية لهذه العناصر. يمكن لـGemini تحسين الحقول داخلها فقط.

## توزيع المسؤوليات

### المحرك الحتمي

- الأعداد والنسب والمعادلات.
- انتشار الإتقان والحكم.
- الربيعات والتشتت والقيم المتطرفة.
- توزيع فئات التدخل.
- اختيار أدوات الجودة التي تحققت شروطها.
- إنشاء العناصر الأساسية ومعرفاتها.

### Gemini

- تعميق التفسير التربوي.
- تحسين وصف الأثر.
- تحسين الإجراء والمسؤول والزمن ومؤشر النجاح.
- إضافة خطة بديلة إلى التدخل نفسه.
- إضافة قيود أو بيانات مطلوبة غير مكررة.

### خادم Supabase

- التحقق من أن `targetId` موجود في العقد المرسل.
- حذف مراجع الأدلة غير الموجودة.
- تطبيق حد الإضافات المسموح لكل عائلة.
- إعادة Delta منضبط لا تقرير كامل.

### محرك المصالحة في المتصفح

- تطبيق التحسينات على الحقول المستهدفة.
- رفض العناصر المجهولة.
- دمج القوائم النصية دون تكرار.
- تثبيت الأعداد المقفلة.
- إخراج نموذج تحليل واحد.

## سياسة الأنواع الأخرى

لا تُفرض أعداد تحليل الدرجات على الاستمارات الأخرى.

- العائلات المتخصصة تسمح عادة باستنتاج جديد واحد عند وجود نمط حقيقي غير ممثل في العقد، ولا تسمح بخطة تدخل أو متابعة موازية.
- النوع الجديد التكيفي يسمح بعدد محدود من الإضافات لأنه لا يملك سجلًا مستقرًا بعد.
- جميع الإضافات تمر بالتشابه الدلالي وحدود العقد.

## معايير القبول

1. لا يظهر تدخل محلي ثم تدخل Gemini للفئة نفسها.
2. لا تظهر دورة متابعة ثانية.
3. الحسابات والأعداد لا تتغير بعد Gemini.
4. أي معرف غير موجود يُرفض.
5. التقرير الرسمي والواجهة وتصدير JSON تستخدم النموذج المصالَح نفسه.
6. ملف الدرجات المرجعي يبقى: 5 استنتاجات، 4 تدخلات، 4 مراحل متابعة.
