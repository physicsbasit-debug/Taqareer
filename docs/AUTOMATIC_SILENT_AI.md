# التحسين الذكي التلقائي الصامت — v0.9.7

## تجربة المستخدم

1. ينفذ المستخدم التحليل كالمعتاد.
2. تظهر الحسابات والرسوم والتقرير المحلي فورًا.
3. يبدأ طلب التحسين الخارجي تلقائيًا في الخلفية.
4. لا تظهر رسالة انتظار، ولا اسم المزود، ولا زر إعادة يدوي.
5. عند النجاح تدمج التحسينات داخل العناصر الأصلية.
6. عند الفشل يبقى التقرير المحلي كاملًا، ويسجل الخطأ في سجل المتصفح الفني فقط.

## اختيار النموذج

- النموذج السريع الافتراضي: `gemini-3.5-flash-lite`.
- إذا كان السر `GEMINI_FAST_MODEL` يحتوي نموذجًا قديمًا أو غير متاح، تنتقل الوظيفة تلقائيًا إلى قائمة النماذج المستقرة التالية.
- لا يحتاج المستخدم إلى تغيير السر فورًا لإكمال العمل، مع استحسان تحديثه لاحقًا إلى النموذج الجديد.

## الثوابت

- التحسين الخارجي لا يغير الحسابات أو الفئات أو عدد التدخلات.
- التحليل المحلي المتخصص هو مصدر الحقيقة.
- لا توجد حلقات إعادة في الواجهة.
