# سجل إصدار تقارير v0.9.3

## Phase 1-C3: Automatic Segment Recovery Manager

### إعادة البناء التشغيلية

- إضافة مدير استعادة آلية فوق خط التحليل المقسّم.
- تنفيذ جولتي استعادة آليتين للجزء المتعثر فقط بعد الطلب الأول.
- إبقاء الأجزاء الناجحة والحسابات والرسوم دون إعادة.
- المحافظة على العداد التراكمي أثناء الاستعادة بدل الرجوع إلى 0/4.
- تصنيف الأخطاء المؤقتة وغير القابلة للإعادة.
- احترام `Retry-After` عند توفره.
- إضافة بيانات خطأ منظمة من Edge Function: `errorCode`, `retryable`, `operation`, `segment`.
- إظهار حالة الاستعادة في الواجهة وملخص الأداء.
- إظهار زر الإعادة اليدوية فقط بعد استنفاد الاستعادة الآلية.

### ما لم يتغير

- معادلات بوصلة الإتقان.
- محللات أنواع الاستمارات.
- تقسيم Gemini إلى أربعة أجزاء.
- عقد المصالحة ومنع التكرار.
- تصميم التقرير الرسمي.
- لا أسرار أو SQL جديدة.
