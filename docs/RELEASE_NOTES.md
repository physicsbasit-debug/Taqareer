# سجل إصدار تقارير v0.9.2

## Phase 1-C3 Fix 2: Segmented Deep Analysis Pipeline

### إعادة البناء

- إلغاء اعتماد الواجهة على استجابة Gemini عميقة أحادية.
- تقسيم التحليل الذكي إلى: التشخيص، الاستنتاجات، التدخلات، والجودة والمتابعة.
- تشغيل الأجزاء الأربعة بالتوازي.
- مصالحة كل جزء ناجح فور وصوله.
- دعم النجاح الجزئي دون فقد النتائج أو الأجزاء الناجحة.
- إعادة الجزء المتعثر فقط بدل إعادة التحليل كله.
- ذاكرة مؤقتة وقياس زمن وحجم حمولة لكل جزء.
- محاولة مختصرة واحدة مستقلة لكل جزء عند `MAX_TOKENS` أو JSON التالف.
- إبقاء عمليتي `analyze` و`enrich` القديمتين للتوافق، بينما تستخدم الواجهة الجديدة `enrich_segment`.

### ما لم يتغير

- معادلات بوصلة الإتقان.
- تطبيع Excel الوزاري.
- الرسوم والفئات والأعداد.
- محللات أنواع الاستمارات.
- عقد المصالحة الحقلية ومنع التكرار.
- تصميم التقرير الرسمي.
- لا أسرار أو SQL جديدة.
