# ملاحظات الإصدار v0.4.0

## الجديد

1. إضافة قارئ Word DOCX محلي يعتمد على بنية OOXML وZIP داخل المتصفح.
2. إضافة قارئ PDF نصي باستخدام PDF.js بإصدار مثبت.
3. استخراج عدة محتويات من المستند الواحد، مثل جدول Word والنص السردي، ثم ترك الاختيار للمستخدم.
4. إضافة مسار احتياطي مرن للصور وPDF الممسوح: معاينة الملف ولصق النص أو الجدول بدل إيقاف العمل.
5. إضافة تحليل تربوي سردي أولي:
   - الموضوعات الأكثر حضورًا.
   - مؤشرات الدليل المباشر.
   - جوانب القوة والتطوير.
   - التوصيات وقابليتها للقياس.
   - إجراء أول مقترح مرتبط بنتيجة التحليل.
6. تحديث تصدير JSON ليحفظ معلومات مصدر الملف وطريقة الاستخراج.
7. إضافة عينات Word وPDF حقيقية للاختبار.

## قرارات مقصودة

- لا نحاول قراءة DOC أو XLS القديمين داخل المتصفح.
- لا نضع مفتاح نموذج ذكاء اصطناعي في الواجهة.
- لا نمنع العمل عند فشل استخراج PDF؛ نفتح مسار المراجعة اليدوية.
- لا نعتمد الاستنتاج السردي آليًا دون مراجعة المستخدم.
