# سجل إصدار تقارير v0.9.1

## Phase 1-C3 Fix 1: Deep Analysis Delta Protocol

### إعادة البناء

- استبدال عقد Delta الكبير بعقد `deepAnalysisUnits + patches`.
- إبقاء Gemini مسؤولًا عن التفسير والتشخيص والقرار التربوي العميق.
- إضافة التفسيرات البديلة وحدود الاستدلال وطلبات البيانات لكل قراءة.
- إضافة خطوات تنفيذ وموارد إلى التدخلات دون إنشاء تدخلات جديدة.
- رفض `MAX_TOKENS` قبل محاولة تحليل JSON.
- إضافة محاولة دلالية مختصرة واحدة عند القطع أو JSON التالف.
- إضافة قياسات للمحاولة وسبب النهاية وعدد القراءات والرقع المقبولة.
- إبطال ذاكرة v0.9.0 تلقائيًا عبر إصدار namespace جديد.

### ما لم يتغير

- معادلات بوصلة الإتقان.
- تطبيع Excel الوزاري.
- الرسوم والفئات والأعداد.
- محللات الأنواع المتخصصة.
- تصميم الهوية الأساسي.
- لا أسرار أو SQL جديدة.
