# ملاحظات الإصدار v0.5.0

## الجديد

1. إضافة عميل ذكاء اصطناعي قابل للضبط من الواجهة.
2. إضافة وظيفة Supabase Edge Function باسم `analyze-educational-form`.
3. استخدام مخرجات JSON منظمة بعقد ثابت للتحليل والقراءة البصرية.
4. إضافة OCR بصري للصور وأول ثلاث صفحات من PDF الممسوح عند الحاجة.
5. الدمج بين الحسابات الحتمية المحلية والتفسير التربوي الذكي.
6. ربط كل استنتاج بمراجع أدلة `row:N` أو `line:N` أو `metric:NAME`.
7. التحقق خادميًا من صحة مراجع الأدلة وخفض ثقة الاستنتاج غير المدعوم.
8. اقتراح أدوات الجودة مع بيان تحقق شروط استخدامها.
9. إنشاء خطة تحسين عملية قابلة للقياس.
10. اقتراح تعريف لنوع استمارة جديد بدل إجباره على نوع معروف.
11. إخفاء الحقول الشخصية المباشرة قبل الإرسال افتراضيًا.
12. الرجوع التلقائي إلى التحليل المحلي عند فشل الاتصال.
13. إضافة نافذة إعداد واختبار الاتصال دون تعديل الشيفرة.

## قرارات مقصودة

- لا يوجد مفتاح OpenAI في الواجهة أو GitHub Pages.
- لا يرسل التطبيق الملف كاملًا إلى التحليل النصي؛ يرسل عينة منظمة ومحدودة.
- لا يُرسل أي محتوى إلى الذكاء الاصطناعي ما لم يكن الاتصال مفعّلًا.
- لا يعتمد التطبيق استنتاجات الذكاء الاصطناعي نهائيًا دون مراجعة بشرية.
- لا يتحول رمز الوصول المشترك إلى بديل مزيف عن الحسابات والصلاحيات؛ هو حماية انتقالية لهذه المرحلة.
