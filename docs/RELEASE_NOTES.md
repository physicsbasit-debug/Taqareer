# سجل إصدار تقارير v0.9.0

## Phase 1-C3: Analytical Reconciliation Architecture

### إعادة البناء

- إضافة `assets/analysis-reconciliation.js` كنواة مستقلة للمصالحة.
- تحويل التحليل المحلي إلى عقد رسمي بمعرفات ثابتة.
- تغيير استدعاء الواجهة من `analyze` إلى `enrich`.
- تغيير استجابة Gemini من تقرير كامل إلى تحسينات Delta.
- تحقق خادمي من معرفات العناصر ومراجع الأدلة.
- دمج حقلي بدل جمع قوائم متوازية.
- اعتماد نموذج تحليل واحد للواجهة والتقرير والتصدير.

### ما تم منعه

- تكرار فئات التدخل الأربع.
- تكرار مراحل المتابعة.
- تغيير أعداد الطلبة أو فئات الإتقان بواسطة Gemini.
- قبول معرفات أو أدلة مختلقة.
- إنشاء صفحة تقرير إضافية لمخرجات Gemini الموازية.

### التوافق

- لا تغيير في معادلات بوصلة الإتقان.
- لا تغيير في تطبيع Excel الوزاري.
- لا أسرار أو SQL جديدة.
- بقيت عملية `analyze` القديمة في الوظيفة للتوافق، لكن الواجهة الجديدة لا تستخدمها.
