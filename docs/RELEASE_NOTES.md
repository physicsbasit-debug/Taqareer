# v0.9.7 — Automatic Silent AI Enhancement

أعاد الإصدار ضبط تجربة التحليل لتكون تلقائية وهادئة:

- الضغط على تنفيذ التحليل يعرض التقرير فورًا ويبدأ التحسين الخارجي تلقائيًا في الخلفية.
- لا توجد رسالة «سيجري Gemini» ولا زر «محاولة تحسين ذكي».
- نجاح التحسين يدمج القراءة الأعمق بصمت، وفشله يترك التقرير المحلي كما هو دون إزعاج المستخدم.
- أخفيت مؤشرات الأداء التقنية من الواجهة الافتراضية، مع إمكانية إظهارها فقط عبر `showPerformanceDiagnostics: true`.
- استبدل النموذج الافتراضي السريع بـ `gemini-3.5-flash-lite`، وهو نموذج مستقر منخفض الكمون.
- أضيف انتقال تلقائي عند خطأ عدم توفر النموذج إلى `gemini-3.1-flash-lite` ثم `gemini-3.6-flash`.
