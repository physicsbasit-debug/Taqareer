# سجل إصدار تقارير v0.9.4

## Phase 1-C3 Fix 3 - Segment Failure Isolation

- فصل محور الجودة والمتابعة إلى مهمتين مستقلتين: أدوات الجودة، والمتابعة والحوكمة.
- إلغاء إعادة طلب المحتوى الفاشل بالحمولة نفسها.
- تفكيك القراءة أو الاستنتاجات أو التدخلات إلى دفعات أهداف صغيرة عند فشل المحتوى.
- قصر الإعادة المتطابقة على خطأ اتصال مؤقت واحد فقط.
- حد تزامن ثلاث مهام لتخفيف ضغط الطلبات المتوازية.
- تخزين مؤقت وقياس زمني على مستوى المهمة.
- إظهار اسم المهمة المتعثرة وسبب الفشل بدل عبارة «3 من 4» المبهمة.
- إعادة المهمة الفاشلة وحدها يدويًا مع حفظ جميع المهام الناجحة.
- إضافة تفاصيل محاولات Edge Function إلى الاستجابة التشخيصية دون كشف البيانات الخام.
- عدم تغيير معادلات بوصلة الإتقان أو محللات الاستمارات أو تصميم التقرير.
