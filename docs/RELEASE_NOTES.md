# ملاحظات إصدار تقارير v0.3.0

## الجديد

- تفعيل قراءة XLSX وXLSM داخل المتصفح.
- دعم المصنفات متعددة الأوراق.
- نافذة لاختيار ورقة العمل.
- اكتشاف صف العناوين عند وجود صفوف تمهيدية.
- قراءة النصوص والأرقام والتواريخ الأساسية.
- إضافة اسم ورقة العمل وصف العناوين إلى تقرير الجودة وملف JSON.
- إضافة ملف Excel نموذجي متعدد الأوراق للاختبار.

## لم يتغير

- منطق التحليل الوصفي والإتقان.
- سياسة القيود المرنة.
- النشر الثابت عبر GitHub Pages.
- عدم إرسال الملفات إلى خادم.

## ملاحظات

صيغة XLS القديمة غير مدعومة في هذه المرحلة. يجب تحويلها إلى XLSX أو CSV.
