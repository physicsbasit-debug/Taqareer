# ملاحظات إصدار تقارير v0.2.0

## المنجز

- تحويل المعاينة السابقة إلى نواة تشغيلية تقرأ CSV وTSV وTXT الجدولي فعليًا.
- دعم لصق الجداول مباشرة من Excel.
- إضافة تعرف أولي على عائلات النماذج الحالية مع مسار لنوع جديد غير مسجل.
- إضافة فحص جودة مرن: يمنع فقط عند غياب البنية أو السجلات، ويعرض بقية الحالات كتنبيهات.
- إضافة تحليل وصفي حتمي للدرجات وتوزيع مستويات الأداء.
- عدم افتراض الدرجة الكلية من أعلى قيمة مرصودة.
- استبعاد القيم السالبة أو الأعلى من الدرجة الكلية المؤكدة مع توضيح ذلك في الاستنتاجات.
- إضافة تصدير JSON وطباعة النتائج.
- إضافة workflow حقيقي ونسخة مرئية احتياطية لمشكلة الملفات المخفية.
- إنشاء `.nojekyll` تلقائيًا داخل GitHub Actions.

## الحدود الحالية

- لا تزال XLSX وPDF وWord والصور غير مفعلة.
- الذكاء الاصطناعي الحالي محرك استدلال محلي، وليس اتصالًا حيًا بمزود خارجي.
- لا يوجد حفظ سحابي أو حسابات مستخدمين في هذا الإصدار.
