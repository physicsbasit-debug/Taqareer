# عقد مخرجات التقارير

## 1. التقرير التنفيذي

الفئة: الإدارة واللجان.

يتضمن:

- تعريف موجز بالمصدر ونطاق التحليل.
- أهم النتائج.
- أبرز جوانب القوة.
- أعلى أولويات التحسين.
- القرارات المطلوبة.
- القيود ودرجة موثوقية التحليل.

## 2. التقرير التحليلي التفصيلي

يتضمن:

- جودة البيانات.
- منهج التحليل.
- المؤشرات والجداول.
- الرسوم وأدوات الجودة.
- الاستنتاجات مع الأدلة.
- التفسيرات والقيود.
- الملحق الحسابي.

## 3. خطة التحسين

| الأولوية | الإجراء | الفئة | المسؤول | الزمن | مؤشر النجاح | أداة المتابعة | الدليل المرتبط |
|---|---|---|---|---|---|---|---|

## 4. التقرير الفردي

يستخدم لطالب أو معلم عند توفر الصلاحية، ويمنع إدراج الأسماء في التقارير العامة.

## 5. التقرير المقارن

- مقارنة فترات.
- مقارنة شعب أو صفوف.
- مقارنة مواد.
- مقارنة مكونات تقويم.

يجب بيان تكافؤ المقاييس والعينات قبل إظهار المقارنة.

## 6. الصيغ

- PDF للطباعة والاعتماد.
- Word للتحرير الرسمي.
- Excel للجداول والبيانات المصرح بها.
- لوحة تفاعلية داخل التطبيق.

## 7. قابلية التتبع

عند الضغط على أي استنتاج أو رسم، يعرض التطبيق:

- البيانات المستخدمة.
- طريقة الحساب.
- مصدر الدليل.
- القيود.
- حالة المراجعة.

## 8. اللغة

- لغة عربية واضحة.
- تجنب العبارات العامة.
- عدم استخدام مصطلح إحصائي دون تفسير مبسط.
- التفريق بصريًا بين حقيقة، استنتاج، وفرضية.
