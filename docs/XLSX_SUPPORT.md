# دعم Excel في تقارير v0.3.0

## الصيغ

| الصيغة | الحالة |
|---|---|
| XLSX | مدعومة |
| XLSM | مدعومة للبيانات، ولا يتم تشغيل وحدات الماكرو |
| XLS | غير مدعومة حاليًا |
| CSV / TSV | مدعومة من المسار السابق |

## السلوك

- يقرأ الملف داخل المتصفح.
- يعرض الأوراق الصالحة للمستخدم عند تعددها.
- لا يغيّر الملف الأصلي.
- لا ينفذ أي ماكرو.
- لا يفترض أن الصف الأول هو صف العناوين.
- لا يبدأ التحليل قبل عرض المعاينة.
