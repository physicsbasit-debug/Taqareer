# معمارية تقارير v1.2.20

## القرار الجذري

لا يوجد «محلل عام» يطبق الإجراء نفسه على كل استمارة. المشترك هو خط الأنابيب التقني فقط، أما التحليل التربوي فيتغير جذريًا بحسب النوع والغرض ووحدة التحليل.

```text
الملف الخام
  ↓
قارئ الصيغة + تطبيع ملفات الوزارة
  ↓
فحص الجودة واستخراج البيانات الوصفية
  ↓
التعرف المحلي + تحقق Gemini عند الحاجة
  ↓
Adaptive Analysis Router
  ├─ نتائج مادة واحدة
  ├─ مكوّن تقويمي
  ├─ توزيع مستويات
  ├─ أداء عبر المواد
  ├─ مؤشرات إشرافية
  ├─ أعمال طلبة
  ├─ تقرير إشرافي سردي
  ├─ استبانة اتجاهات أو رضا
  ├─ احتياجات تدريبية
  ├─ تقييم برنامج أو مبادرة
  ├─ سلوك وغياب وانضباط
  └─ نوع جديد / عقد تحليل مقترح
  ↓
محرك حتمي متخصص + تفسير Gemini متخصص
  ↓
عقد رسوم دلالي: intent + data semantics
  ↓
Global Visualization Engine
  ├─ مقارنة وترتيب → Bar
  ├─ توزيع عددي → Histogram
  ├─ تركيب فئات → 100% Stacked
  ├─ اتجاه زمني → Line
  ├─ ملف أبعاد محدود → Radar
  ├─ حالي مقابل مستهدف → Bullet
  ├─ قبل/بعد → Dumbbell
  ├─ علاقة رقمية → Scatter
  └─ فجوات أولوية → Pareto
  ↓
أدلة + رسوم + أدوات جودة + خطة تدخل + متابعة
  ↓
واجهة مراجعة + تقرير رسمي عميق
```

## ما هو مشترك؟

- استقبال Word وExcel وPDF والصور.
- تنظيف البنية وفحص الجودة.
- إخفاء البيانات الشخصية.
- عقد الأدلة ودرجات الثقة.
- عرض النتائج وتصديرها.

## ما لا يُوحّد؟

- المؤشرات المحسوبة.
- **بيانات الرسم والغرض التحليلي** يحددهما المحلل المتخصص، أما **اختيار الشكل وقواعد القراءة البصرية** فتديرهما طبقة مشتركة.
- شروط أدوات الجودة.
- قواعد التشخيص.
- الاستنتاجات المسموحة والممنوعة.
- التدخلات وخطة المتابعة.
- بنية التقرير التفسيري.

## عقد المخرجات المشترك

العقد موحد كي تستطيع الواجهة والتقرير عرضه، لا كي يتوحد منطق التحليل:

- `analysisProfile`
- `metrics`
- `charts`
- `diagnosticSections`
- `findings`
- `qualityTools`
- `improvementPlan`
- `monitoringPlan`
- `limitations`
- `evidenceMap`

## أمثلة على اختلاف المنهج

- الدرجات: ربيعات، تشتت، قيم متطرفة، حساسية الإتقان وفئات التدخل.
- الاستبانة: ليكرت، فجوات البنود، باريتو، واتساق داخلي مشروط.
- الاحتياجات التدريبية: أهمية × فجوة أداء × عدد مستفيدين، ثم قياس نقل الأثر.
- البرنامج: فصل جودة التنفيذ عن المخرجات والأثر والاستدامة.
- السلوك والغياب: باريتو، اتجاه زمني، حالات متكررة وإنذار مبكر دون وصم.
- التقرير السردي: قوة الدليل، الاتساق بين التشخيص والدعم والتوصية، التكرار والتناقض والتواريخ.

## النوع الجديد

1. لا يُجبر على أقرب نوع معروف.
2. يُبنى ملف للحقول الرقمية والفئوية والزمنية والنصية.
3. يطبق تحليلًا استكشافيًا مناسبًا لما هو موجود فقط.
4. يطلب الهدف والمعيار ووحدة التحليل والقرارات المطلوبة.
5. يقترح Gemini عقد تحليل متخصصًا للمراجعة.
6. لا يُعتمد تقرير نهائي تشخيصي قبل اعتماد العقد من المستخدم.


## عقد الإتقان المشترك v0.8.0

`assets/mastery-metrics.js` هو مصدر الحقيقة الوحيد لمعادلات انتشار الإتقان. يعتمد عليه محلل الدرجات ومقارنة المواد، بينما لا تستخدمه الأنواع التي لا تمثل درجات فردية قابلة للمقارنة بحد إتقان. Gemini يفسر النتائج ولا يعيد حسابها.

## محرك الرسوم الدلالي المشترك v1.2.20

`assets/visualization-policy.js` هو الحد الفاصل بين التحليل والرسم. المحلل المتخصص ينتج البيانات والغرض، ولا يقرر الشكل النهائي لمجرد أن البيانات رقمية. المحرك المشترك يطبق السياسة على جميع الأنواع، بما فيها الأنواع الجديدة.

قواعد أساسية:

- لا يستخدم Radar إذا تجاوزت الأبعاد 8؛ يعود إلى Bar قابل للقراءة.
- التوزيعات الرقمية المتصلة تستخدم Histogram عندما تتوفر فئات رقمية مناسبة.
- التركيبات المتبادلة أو مستويات الأداء المحدودة تستخدم 100% Stacked.
- الحالي مقابل المستهدف يستخدم Bullet عند توفر القيمتين.
- قبل/بعد يستخدم Dumbbell.
- الزمن يستخدم Line عندما توجد نقطتان أو أكثر، مع أولوية ثلاث نقاط فأكثر للتحليل الاتجاهي.
- الفجوات المرتبة تستخدم Pareto مع النسبة التراكمية.
- العلاقة العددية تستخدم Scatter فقط عند وجود محورين رقميين صالحين.
- Heatmap وBox وTable تبقى أدوات متخصصة عندما يثبت معناها التحليلي.

هذه السياسة **عامة** ولا ترتبط باسم نوع تقرير محدد.
