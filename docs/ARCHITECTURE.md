# ملاحظة معمارية v0.3.0

## طبقة استقبال البيانات

تستخدم النسخة الحالية مسارين:

1. قارئ النصوص الجدولية لـ CSV وTSV وTXT واللصق.
2. قارئ Excel محلي خفيف داخل `assets/xlsx-lite.js`.

## قارئ Excel

لا يعتمد على خدمة خارجية. يقوم بالآتي داخل المتصفح:

- قراءة حاوية XLSX المضغوطة.
- استخراج تعريف أوراق العمل والعلاقات الداخلية.
- قراءة النصوص المشتركة والأنماط الأساسية.
- تحويل الخلايا إلى مصفوفة صفوف وأعمدة.
- البحث عن صف العناوين ضمن أول 25 صفًا.
- إنشاء جدول من الورقة وعرضه للمستخدم قبل التحليل.

## الحدود المقصودة

القارئ ليس بديلًا كاملًا لمحرك Excel المكتبي. هو طبقة استقبال آمنة ومحدودة موجهة للجداول التربوية الشائعة. إذا لم يجد جدولًا واضحًا، يوقف الاستيراد برسالة مفهومة بدل تمرير بيانات مضللة.

## الخطوة اللاحقة

بناء طبقة استخراج موحدة لـ PDF وWord والصور، ثم تمرير ناتجها إلى العقد نفسه:

```text
headers + rows + source metadata
```
