# ملاحظة معمارية v0.2.0

## المبدأ

واجهة المستخدم بسيطة، بينما تنقسم النواة إلى أربع وظائف واضحة:

1. `parseDelimited`: قراءة البيانات الجدولية.
2. `classify`: التعرف القائم على إشارات قابلة للتوسعة.
3. `assessQuality`: التحقق المرن الذي يمنع الحالات الحرجة فقط.
4. `runAnalysis`: حسابات حتمية ثم صياغة استنتاجات محلية موثقة.

## الذكاء الاصطناعي

الوضع الحالي محلي وآمن. الربط الحي يجب أن يمر عبر Edge Function أو Backend حتى لا يظهر مفتاح المزود في المتصفح. لا تُرسل أسماء الطلبة إلى المزود إلا عند ضرورة معلنة، ويفضل استبدالها بمعرفات داخلية.

## قاعدة القيود

- مانع: ملف فارغ، غياب العناوين، غياب السجلات، أو عدم وجود عمود رقمي عند طلب تحليل الدرجات.
- تنبيه: قيم مفقودة، تكرار، نوع جديد، أو عدم تأكيد الدرجة الكلية.
- لا يُفترض الحد الأعلى للدرجة من أعلى قيمة مرصودة.
