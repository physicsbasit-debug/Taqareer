# معمارية تقارير v0.5.0

## المسار التشغيلي

```text
ملف المستخدم
  ↓
قارئ محلي حسب الصيغة
  ↓
معاينة المستخدم
  ↓
فحص الجودة والحسابات الحتمية
  ↓
[اختياري] إخفاء الحقول الشخصية وبناء حمولة محدودة
  ↓
Supabase Edge Function
  ↓
OpenAI Responses API بمخرج JSON منظم
  ↓
التحقق من مراجع الأدلة
  ↓
دمج النتائج الذكية بالحسابات المحلية
  ↓
تقرير وخطة تحسين قابلة للمراجعة
```

## ملفات الواجهة

```text
assets/runtime-config.js   إعدادات افتراضية بلا أسرار
assets/ai-client.js        الاتصال بوظيفة Supabase
assets/xlsx-lite.js        قراءة Excel
assets/document-lite.js    قراءة Word وPDF والصور
assets/app.js              رحلة المستخدم والتحليل المحلي والدمج
assets/styles.css          الواجهة RTL
```

## ملفات الخادم

```text
supabase/functions/analyze-educational-form/index.ts
```

الوظيفة مسؤولة عن:

- فحص النطاق ورمز الوصول وحجم الطلب.
- الاحتفاظ بمفتاح OpenAI بعيدًا عن المتصفح.
- استدعاء نموذج يدعم النص والصورة.
- إلزام الرد بعقد JSON ثابت.
- التحقق من صحة مراجع الأدلة.

## قاعدة الاستمرارية

فشل الذكاء الاصطناعي لا يلغي التحليل المحلي. هذه قاعدة معمارية، لا رسالة تجميلية تظهر بعد الكارثة.
