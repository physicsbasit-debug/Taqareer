# الأمن والخصوصية في v0.5.0

## ما تم تنفيذه

- مفتاح OpenAI موجود في Supabase فقط.
- السماح بطلبات المتصفح من نطاقات محددة.
- رمز وصول مشترك محفوظ في أسرار Supabase.
- مقارنة رمز الوصول بطريقة ثابتة زمنيًا بعد تجزئته.
- حد لحجم الطلب وعدد الصور وحجم كل صورة.
- عدم تخزين ردود OpenAI بواسطة الطلب `store: false`.
- إخفاء الحقول الشخصية المباشرة قبل التحليل النصي افتراضيًا.
- الاحتفاظ برمز الوصول في جلسة المتصفح فقط.
- عدم تعطيل التحليل المحلي عند فشل الخدمة الخارجية.

## ما لا توفره هذه المرحلة

- حسابات فردية.
- صلاحيات بحسب الدور.
- تسجيل تدقيق للمستخدمين.
- تحديد معدل طلبات دائم لكل مستخدم.
- تشفير سحابي لمشاريع محفوظة، لأن الحفظ السحابي غير موجود بعد.

## تعليمات الاستخدام

- راجع النصوص الحرة؛ قد تحتوي أسماء لا يمكن اكتشافها آليًا بصورة كاملة.
- اترك خيار إخفاء البيانات الشخصية مفعّلًا إلا عند ضرورة واضحة ومصرح بها.
- لا تستخدم رمز وصول سهلًا أو مشتركًا خارج المدرسة.
- لا تنشر مفتاح OpenAI أو رمز الوصول داخل GitHub.
- لا تعتمد التقرير الذكي قبل مراجعة الاستخراج والأدلة.

## قرار المرحلة

الحماية الحالية مناسبة للتجريب المنضبط داخل نطاق محدود. قبل التوسع المؤسسي يجب إضافة تسجيل دخول وصلاحيات ومعدل طلبات وسجل تدقيق.
