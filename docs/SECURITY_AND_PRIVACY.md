# الأمن والخصوصية في تقارير v0.7.0

- مفتاح Gemini يبقى في أسرار Supabase فقط.
- رابط الوظيفة والمفتاح العام فقط يُحفظان في المتصفح.
- رمز الوصول يبقى في جلسة المتصفح.
- حقول الأسماء والمعرفات المباشرة تُحجب افتراضيًا قبل التحليل الذكي.
- طلب التحقق من النوع يرسل عينة محدودة، لا ملف Excel كاملًا.
- التطبيع والحسابات والإحصاءات الأساسية تتم محليًا في المتصفح.
- Gemini يستقبل النتيجة الحتمية ومراجع أدلة محددة، لا يملك حق اختراع حسابات بديلة.
- وظيفة Supabase تحذف إحالات الأدلة غير الموجودة وتخفض الثقة عند فقد الدليل.
- لا تنشر `GEMINI_API_KEY` أو `TAQAREER_ACCESS_CODE` في GitHub أو صور الشاشة.
- التقرير العام لا يعرض أسماء الأفراد افتراضيًا.
