# محرك تطبيع ملفات Excel الوزارية

## المشكلة

ملفات Excel الصادرة من أنظمة الوزارة غالبًا تقارير طباعة وليست جداول تحليلية نظيفة. قد تحتوي على:

- خلايا مدمجة أفقيًا ورأسيًا.
- أعمدة ضيقة تستخدم كفواصل بصرية.
- صفوف بارتفاع أقل من نقطة واحدة بين السجلات.
- ترويسة وزارة ومدرسة وتاريخ قبل الجدول.
- رؤوس متعددة المستويات أو مكررة بين الصفحات.
- حقول اختيارية فارغة في جميع السجلات.
- ترتيب RTL لا يطابق ترتيب الأعمدة المادي داخل XML.

## مسار التطبيع

```text
قراءة OOXML
→ استخراج القيم والدمج والعروض والارتفاعات
→ اكتشاف نطاق العناوين
→ بناء أعمدة منطقية من الخلايا المدمجة
→ حذف الفواصل الطباعية
→ فصل البيانات الوصفية
→ إعادة ترتيب RTL
→ التحقق من السجلات
→ التصنيف والتحليل
```

## الضوابط

- لا يُحذف سجل يحتوي بيانات أساسية.
- لا تُدمج قيمتان مختلفتان بصمت؛ عند وجود أكثر من قيمة داخل الحقل المنطقي تُفصل بعلامة واضحة للمراجعة.
- لا تُعد «ملاحظات» الفارغة نقصًا في كشف الدرجات.
- يحتفظ النظام بتشخيص يوضح عدد الصفوف والأعمدة الأصلية والخلايا المدمجة وما بقي بعد التطبيع.
- المستخدم يراجع الجدول الناتج قبل التحليل.
