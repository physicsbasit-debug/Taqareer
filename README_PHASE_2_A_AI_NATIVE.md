# Phase 2-A — AI-Native Analytical Core

## الهدف

نقل ملكية التحليل التربوي من القوالب المحلية إلى الذكاء الاصطناعي، مع إبقاء الحسابات والأرقام والرسوم تحت سيطرة الكود المحلي.

## العقد الجديد

```text
الملف
→ استخراج وتنظيف محلي
→ حساب مؤشرات ورسوم ومراجع أدلة
→ analyze_primary
→ تحقق خادمي من الأدلة والاكتمال
→ تحقق محلي ثانٍ
→ عرض النتيجة والتقرير
```

## ما توقف

- عرض الاستنتاجات المحلية القالبية كتحليل نهائي.
- التحسين اللاحق لنص محلي مكتمل.
- العدد المقفل للاستنتاجات والتدخلات.
- إظهار تقرير محلي منمق عند فشل الذكاء الاصطناعي.
- إعادة استخدام تحليل تربوي مخزن للملف نفسه.

## ما بقي محليًا

- قراءة الملفات.
- التحقق من الجودة.
- المتوسطات والنسب والتشتت والربيعات والإتقان.
- الرسوم والتوزيعات.
- مراجع الأدلة.
- حماية الأرقام من التعديل.

## ما أصبح ملكًا للذكاء الاصطناعي

- القراءة التشخيصية.
- كشف العلاقات والتعارضات والأولويات.
- التمييز بين الحقيقة والاستنتاج والفرضية.
- بناء التدخلات ومؤشرات النجاح وخطة المتابعة.
- تحديد حدود الاستدلال والبيانات الناقصة.
