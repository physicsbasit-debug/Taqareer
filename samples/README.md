# عينات اختبار تقارير

- `student_results_multi_sheet.xlsx`: ملف Excel متعدد الأوراق.
- `student_results_single_subject.csv`: نتائج مادة واحدة.
- `supervision_indicators.csv`: مؤشرات زيارة إشرافية رقمية.
- `supervision_narrative.docx`: تقرير إشرافي سردي مع جدول مؤشرات.
- `student_results_report.pdf`: كشف نتائج عربي يحتوي طبقة نصية فعلية.

العينات مصطنعة لأغراض الاختبار ولا تمثل بيانات حقيقية لأشخاص.
