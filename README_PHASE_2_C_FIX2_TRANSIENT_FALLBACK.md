# Phase 2-C Fix 2 - تبديل تلقائي عند ازدحام Gemini

الإصدار: `v1.1.2`  
عقد التحليل: `6.6.0`  
Edge: `V0.14.1`

## المشكلة

أعاد Gemini خطأ `503` بالنص الإنجليزي: النموذج تحت طلب مرتفع مؤقتًا. كانت وظيفة Edge تعيد محاولة النموذج نفسه فقط، ثم تتوقف؛ ولم تكن تنتقل إلى نموذج بديل لأن التبديل كان محصورًا في أخطاء 404 وعدم توفر اسم النموذج.

## العلاج

- إعادة الطلب مرتين للنموذج نفسه بتراجع أُسّي مع jitter.
- التحول إلى النموذج التالي عند `408/429/5xx` أو رسائل high demand/overload.
- ترتيب التحليل الأساسي: 3.5 Flash ثم 3.6 Flash ثم 3.5 Flash-Lite.
- الحفاظ على مسار الإنقاذ `minimal` للمخرجات الناقصة فقط.
- تعريب الرسائل النهائية وإخفاء رسالة مزود الخدمة الخام.
- تعليم الخطأ المؤقت بـ`retryable: true`.

## غير المتغير

- محرك الزيارات المتعددة، المقياس المعكوس، الخصوصية، الرسوم، الحارس العددي، بوابة الأدلة، عقد 6.6.0، والتفكير المضبوط.
