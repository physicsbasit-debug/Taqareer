# Phase 2-C Fix 1 - اكتمال رسوم الزيارات وصفوف التقرير

الإصدار: `v1.1.1`

## المشكلة

في تقرير الزيارات الإشرافية المتعددة ظهرت بطاقتا الرسم في الصفحة التنفيذية، لكن محتوى الرسمين كان خارج المساحة الآمنة للطباعة بسبب ازدحام الصفحة بالعنوان والبيانات والمؤشرات. كما ظهر حقل الصف/الفئة على أنه غير محدد رغم أن الزيارات تشمل الصفوف الثامن والتاسع والعاشر.

## الحل

- إبقاء الصفحة التنفيذية للملخص والمؤشرات فقط في نوع `supervision_multi_visit`.
- نقل الرسوم الأربعة إلى الصفحات التحليلية الآمنة للطباعة.
- ترتيب الرسوم بحيث يظهر توزيع المستويات والاتساق الرقمي/السردي معًا، ثم يظهر مخطط المؤشرات الثلاثة عشر بعرض كامل مع مقارنة الزيارات.
- محاذاة محتوى الرسوم الكثيفة إلى أعلى البطاقة لمنع اختفائه عند حدود الصفحة.
- تجميع الصفوف المستخرجة من الزيارات وعرض `8-10` عندما تكون الصفوف الثامن والتاسع والعاشر موجودة.

## المكتسبات المحفوظة

- لا تغيير في استخراج الزيارات أو 91 تقديرًا.
- لا تغيير في المقياس المعكوس.
- لا تغيير في Gemini أو عقد التحليل `6.6.0`.
- لا تغيير في Supabase Edge `V0.14.0`.
- لا تغيير في الخصوصية أو ربط الدليل السردي بالتقدير داخل الزيارة.
- لا SQL ولا أسرار جديدة.
